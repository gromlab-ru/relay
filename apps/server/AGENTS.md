# Server: обязательные правила

Прочитай `../../docs/development/INTERFACE-STANDARD.md`.
Запуск сервера — пользовательский интерфейс: русская справка, понятные адреса,
выбранный конфиг, ошибки подключения и корректное завершение процесса.
Разделяй dev-настройки и поведение установленного пакета. Не зашивай путь к личному проекту.
Бизнес-логика принадлежит Core/server-runtime. В публичных контрактах явно обозначай Markdown.
Проверяй поставку встроенного Web и запуск из каталога без исходников.
