# MCP: обязательные правила

Прочитай `../../docs/development/INTERFACE-STANDARD.md` перед изменением инструмента.

- Инструменты — интерфейс взаимодействия человека с действиями агента.
- Имена должны различать предметные действия; описание и каждый публичный параметр
  обязательны и написаны по-русски. Вложенные поля также документируются.
- Не скрывай название, действие и целевые ID внутри универсального объекта команды,
  когда можно дать типизированный предметный инструмент.
- Полное описание принимает Markdown, краткое — многострочный обычный текст.
- Изменения выполняются через общий backend, без копирования бизнес-логики.
- Ответ записи содержит понятную квитанцию и структурированный результат; повтор запроса
  не выдаёт текущее состояние за первоначальный результат.
- Списки ограничены, большой контекст запрашивается адресно. Ошибки и ограничения объясняются.
- Проверяй discovery-схемы, успешный вызов, повтор, конфликт, изоляцию проектов и бюджет ответа.
  Представление строки вызова проверяется отдельно в MCP-клиенте.
- После изменения инструмента обнови справочник MCP и исходники скилла Relay.
