# История изменений Relay MCP

## Не выпущено

- Порт MCP по умолчанию изменён с `3010` на `4710`; endpoint — `/mcp`.
- При подключении по конфигурации без явного порта Relay Server используется `4700`.
  Флаги, переменные окружения и явные настройки сохраняют приоритет.

## 0.2.0

- Инструменты `project_context`, `project_records`, `project_record_get`,
  `project_record_save`, `task_briefing` и `checkpoint_changes` для полного цикла проекта.
- Паспорт, планы, этапы, требования, знания, контекст задач и багов, исполнения,
  проверки, приёмка, вопросы, релизы, установки и контрольные точки через общий Relay Server.
- Компактный контекст оркестратора с полными счётчиками и ограниченное поручение работнику.
- Фильтры задач по плану, этапу и виду работы; ревизионное обновление документов,
  идемпотентное создание и раздельный учёт попытки, приёмки и выпуска.
- Самостоятельный скилл `relay` с ролевыми алгоритмами, автоматически формируемыми
  справочниками и проверенным MCP-сценарием.

Для новых операций требуется `@gromlab/relay-server@0.2.0` или совместимая более новая версия.

## 0.1.1

- Исправлен запуск публикации в GitHub Actions через `pnpm run`.
- Первый автоматический выпуск Relay MCP через npm Trusted Publishing с provenance.

## 0.1.0

- Самостоятельный npm-пакет `@gromlab/relay-mcp` со Streamable HTTP и одновременным доступом агентов.
- Подключение к Relay Server в режимах local/workspace; явный URL, `--config` и автоматический поиск.
- Горячее чтение конфигурации, постоянная регистрация проектов, изоляция авторов и задач.
- Операции и управление реестром через общий REST SDK; проектные API принадлежат Relay Server.
- Инструменты задач, назначения, зависимостей, обзора, комментариев и отчётов; курсоры, выбор полей и ограничение ответа.
- Самодостаточный npm-архив, проверка установки и независимые релизы `mcp-v<version>`.
