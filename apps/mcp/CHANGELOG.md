# История изменений Tasks MCP

## 0.1.0

- Самостоятельный npm-пакет `@gromlab/tasks-mcp` со Streamable HTTP и одновременным доступом агентов.
- Один проект через `tasks.config.json` или реестр `tasks.orchestrator.json`; явный `--config` и автоматический поиск.
- Горячее чтение конфигурации, постоянная регистрация проектов, изоляция авторов и задач.
- Операции через общий REST SDK; автоматический запуск локальных REST API при отсутствии URL.
- Инструменты задач, назначения, зависимостей, обзора, комментариев и отчётов; курсоры, выбор полей и ограничение ответа.
- Самодостаточный npm-архив, проверка установки и независимые релизы `mcp-v<version>`.
