- `pnpm --filter @tasks/playground run demo:check` — совпадение с эталоном,

### Замечания к текущему интерфейсу

1. **Доступность блока кода.** Axe-core 4.12.1 на #82 при ширине 390 обнаружил
   `scrollable-region-focusable` для `pre`: горизонтально прокручиваемый блок JSON
   не имеет клавиатурного фокуса. Это воспроизводимый пограничный случай длинного Markdown.
2. **Быстрый посимвольный ввод.** В автоматизированной попытке `keyboard type "101"`
   после `/` поле содержало `1`. Этот способ ввода не отмечен как успешно проверенный;
   требуется отдельная диагностика взаимодействия ввода и перерисовок.
   Полное заполнение поиска через `fill` и поиск по описанию отработали корректно.
3. В консоли есть warning React Router о leaf route `/tasks/...` без `element`.
   Карточки при этом открывались. Аудит также оставил ручную проверку контраста
   ID корневой карточки под открытой панелью как `incomplete`.

Аудит доступности имеет замечание и **не считается полностью пройденным**.
Эти наблюдения относятся к интерфейсу трекера и не добавлены в продуктовый backlog
арендного сервиса, чтобы сохранить целостность легенды.
