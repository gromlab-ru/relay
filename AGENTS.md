# Скиллы проекта

- Четыре внешних скилла разработки перечислены в `skills-lock.json`.
  Для установки из корня проекта: `pnpm run skills:install` (Node.js 22.20+, рекомендуется 24).
- Весь каталог `.agents/skills` исключён из Git, включая локально добавленные скиллы.
- `src-skills/relay` — исходники продуктового скилла Relay; главный файл — `skill.md`.
- `skills/relay` — готовый распространяемый пакет. Получай его командой `pnpm run skills:build`,
  проверяй через `pnpm run skills:check`. Ручные правки результата перезаписываются сборкой.
- Сборщик находится в `scripts/skill-bundle`. Другие каталоги с именем `skills` для исходников
  или сборщиков не создаются. Только готовый пакет содержит обнаруживаемый `SKILL.md`.
- Установленная копия `.agents/skills/relay` обновляется установщиком; редактируются исходники.
