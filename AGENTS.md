# Обязательный протокол разработки

- До проектирования прочитай [единые правила](docs/development/INTERFACE-STANDARD.md)
  и инструкции ближайшего владельца. Они действуют для всех интерфейсов, не только Web.
- Заголовок — однострочный текст; краткое описание — многострочный обычный текст;
  полное описание, инструкция, требования и документация — Markdown.
  В JSON-хранилище Markdown представлен массивом строк. Внешний API может принимать
  строку Markdown; преобразование принадлежит слою хранения.
- CLI по умолчанию предназначен человеку: собственное представление команды,
  форматирование Markdown, таблицы, переносы, пустые состояния и пагинация.
  Вывод внутренних объектов не заменяет интерфейс. Машинный контракт — `--format json`.
- MCP-инструмент должен объяснять действие своим именем, описанием и аргументами;
  значимые параметры доступны без раскрытия непрозрачного объекта операции.
- Отсутствие русского описания команды, инструмента или публичного аргумента —
  нарушение протокола. Документация, комментарии, JSDoc и пользовательские сообщения
  пишутся по-русски. Технические идентификаторы и цитируемые внешние материалы не переводятся.
- До реализации зафиксируй владельца, контракты, человеческий сценарий и проверки.
  Для хранения определи совместимость и миграцию; для списков — границы и продолжение.
- Перед завершением проверь человеческий вывод и машинный ответ отдельно.
  Успешная компиляция или возможность получить JSON не подтверждают качество интерфейса.

# Git и pull requests

- Изменения готовятся в отдельной тематической ветке и предлагаются через pull request.
- Не коммить и не отправляй изменения напрямую в `main` или `master`.
- Слияние pull request выполняется только по явному поручению пользователя.

# Скиллы проекта

- Четыре внешних скилла разработки перечислены в `skills-lock.json`.
  Для установки из корня проекта: `pnpm run skills:install` (Node.js 22.20+, рекомендуется 24).
- Весь каталог `.agents/skills` исключён из Git, включая локально добавленные скиллы.
- `src-skills/relay` — исходники продуктового скилла Relay; главный файл — `skill.md`.
- `skills/relay` — готовый распространяемый пакет. Получай его командой `pnpm run skills:build`,
  проверяй через `pnpm run skills:check`. Ручные правки результата перезаписываются сборкой.
- Сборщик находится в `scripts/skill-bundle`. Другие каталоги с именем `skills` для исходников
  или сборщиков не создаются. Только готовый пакет содержит обнаруживаемый `SKILL.md`.
- Установленная копия `.agents/skills/relay` обновляется установщиком; редактируются исходники.
