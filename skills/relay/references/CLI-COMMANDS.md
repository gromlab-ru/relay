# Команды Relay CLI

Справочник сформирован из зарегистрированных команд. Порядок работы и примеры — в [главном руководстве](../SKILL.md) и [сценариях](EXAMPLES.md).

`relay-cli` означает установленную команду или `npx @gromlab/relay-cli`. В workspace указывайте проект префиксом либо `--project`. Конкретный help: `relay-cli <команда> --help`.

## Общие параметры

| Параметр              | Назначение                                                                     |
| --------------------- | ------------------------------------------------------------------------------ |
| `-V, --version`       | Показать версию CLI                                                            |
| `--config <path>`     | Путь к .relay/config.json или relay.workspace.json; приоритет над RELAY_CONFIG |
| `--project <name>`    | Имя проекта из workspace; также relay-cli <проект> <команда>                   |
| `--server-url <url>`  | Адрес сервера; приоритет над RELAY_SERVER_URL и server.url                     |
| `--local`             | Работать напрямую с локальным Core, игнорируя HTTP-настройки                   |
| `--actor <id>`        | Автор записи, например human; приоритет над RELAY_ACTOR                        |
| `--format <format>`   | Формат ответа Значения: json, text.                                            |
| `--color <mode>`      | Цветовая подсветка (по умолчанию auto) Значения: auto, always, never.          |
| `--max-bytes <bytes>` | Максимальный размер ответа UTF-8                                               |

## create

**Синтаксис:** `relay-cli create [options] [title]`.

Создать задачу и получить её ID

| Аргумент | Назначение                                |
| -------- | ----------------------------------------- |
| `title`  | Название в кавычках; альтернатива --title |

| Параметр                    | Назначение                                                   |
| --------------------------- | ------------------------------------------------------------ |
| `--title <text>`            | Название задачи; при create можно передать первым аргументом |
| `--description <text>`      | Markdown-описание; пустая строка очищает поле                |

| `--stdin`                   | Прочитать описание из stdin                                  |
| `--summary <text>`          | Краткий актуальный результат; пустая строка очищает поле     |
| `--summary-file <path>`     | Результат из UTF-8 файла; - означает stdin                   |
| `--status <status>`         | Статус из .relay/config.json; список: config get             |
| `--group <name>`            | Основная группа                                              |
| `--clear-group`             | Убрать группу                                                |
| `--parent <id>`             | Числовой ID родителя, например 1                             |
| `--clear-parent`            | Убрать родителя                                              |
| `--tags <tags>`             | Теги через запятую; пустая строка очищает теги               |
| `--depends-on <ids>`        | Заменить зависимости: 1,2,3; пустая строка очищает           |
| `--assignee <actor>`        | Назначить исполнителя                                        |

## list

**Синтаксис:** `relay-cli list [options]`.

Показать незавершённые задачи по группам

| Параметр             | Назначение                                                       |
| -------------------- | ---------------------------------------------------------------- |
| `--limit <count>`    | Размер страницы, от 1 до 100                                     |
| `--cursor <cursor>`  | Курсор из предыдущего ответа; фильтры должны совпадать           |
| `--all`              | Все статусы, включая завершённые и отменённые                    |

| `--stage-id <id>`    | Задачи этапа плана                                               |

| `--tag <tag>`        | Задачи с указанным тегом                                         |
| `--sort <order>`     | Порядок: id (по умолчанию) или board                             |
| `--search <text>`    | Поиск в названии, описании и результате без учёта регистра       |
| `--ready`            | Свободные задачи с выполненными зависимостями                    |
