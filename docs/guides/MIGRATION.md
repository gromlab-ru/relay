# Обновление пакетов и данных

CLI, Server и MCP выпускаются согласованным комплектом. Версия пакета и версия JSON-схемы
независимы. `relay-cli --version` показывает версию установленного CLI.
После обновления перезапустите собственные серверные процессы с прежней конфигурацией.

## Действующие миграции

- `relay-cli --local product migrate` переносит продуктовую схему с сохранением ID,
  Markdown, ревизий и квитанций. [Контракт](../reference/PRODUCT.md#json-хранилище).
- `relay-cli --local graph migrate` переносит граф v1 в раздельное хранилище v2.
  `graph reindex` восстанавливает производные индексы. [Контракт](../reference/GRAPH.md#переход-с-v1-и-обслуживание).
- Формат задач отдельных досок совместимо читается владельцем канбана.
  [Схема и восстановление](../reference/KANBAN.md).

Выберите конфиг нужного проекта через `--config`. Сохраните исходные данные и остановите
несовместимые старые клиенты перед миграцией. Прерванные составные записи восстанавливаются
под общей блокировкой. После переноса выполните `relay-cli validate` и проверьте содержимое.

Миграция прежней числовой доски удалена вместе с её моделью; преобразования старых задач
в новый канбан нет. Workspace, регистрации и правила выбора транспорта не изменены.
