# Веб-доска

[Документация](../README.md) → Практические руководства → Веб-доска

В основном сценарии человек наблюдает здесь за работой оркестратора и субагентов:
какие задачи поставлены, кто работает, что заблокировано и какие результаты получены.
Все участники работают на одном хосте. При необходимости человек может дополнить
план, уточнить карточку или оставить комментарий через интерфейс.

## Запуск

В настроенном проекте:

```bash
npx @gromlab/relay-server --actor human --open
```

Один сервер отдаёт доску на `/`, API на `/api/v1` и Swagger на `/api/docs`.
По умолчанию адрес — http://127.0.0.1:4700. Порт можно изменить через `--port`
или [конфигурацию](../reference/CONFIGURATION.md#порт-и-url). `Ctrl+C` останавливает сервер.
Автор серверного запуска используется для изменений из интерфейса.

## Навигация и выборка

Все статусы проекта представлены колонками, включая выполненные и отменённые.
Их порядок и семантика задаются в `.relay/config.json`.

- Группы показывают полное число задач, включая конечные статусы.
- «Без группы» соответствует `group: null`.
- Счётчики групп независимы от поиска и количества загруженных карточек.
- Поиск включает ID, название, описание и summary; дополнительные фильтры сужают выборку.
- Фильтры сохраняются в URL и отдельно для проекта. Переходы между группами
  поддерживают Back/Forward.
- Колонка начинает с 40 карточек; кнопка «Показать ещё» загружает продолжение.
- Вертикальная прокрутка общая для доски, на узком экране доступна горизонтальная.

## Задачи и история

«Создать задачу» открывает форму с выбранной группой. Нажатие на карточку открывает
боковую панель по адресу `/projects/<projectId>/tasks/<id>`. Этой ссылкой можно поделиться с другим
клиентом того же локального сервера. На узком экране панель занимает всю ширину.

В редакторе доступны поля карточки, Markdown, исполнитель, подзадачи и зависимости.
Правки сохраняются явно. Комментарии предназначены для обсуждения, отчёты — для
хода работы и результатов; история читается страницами.
Ссылки на задачи в Markdown сохраняют контекст навигации доски.

## Перенос карточек

Перетащите карточку в нужную колонку или на другую позицию внутри текущей.
Сервер атомарно сохраняет статус и порядок. Те же ограничения зависимостей
действуют и при смене статуса обычным контролом в редакторе.

Для клавиатурного переноса сфокусируйте ручку карточки, нажмите пробел,
выберите положение стрелками и подтвердите пробелом. Escape отменяет перенос.

## Черновики и совместная работа

Черновики редактора, создания, комментариев и отчётов сохраняются локально в браузере
и разделены между вкладками и проектами. Переключение проекта не переносит ввод
в другой проект; черновик хранит исходную ревизию своей записи.

SSE сообщает об изменениях из CLI, API и других вкладок; интерфейс перечитывает данные.
При сетевом сбое сохраняются последние данные и введённый текст. После восстановления
серверного соединения доска обновляется автоматически.

При изменении карточки другим участником черновик сохраняет исходную ревизию.
Попытка сохранить устаревшую версию открывает сравнение: выберите значения спорных
полей и явно сохраните объединённый результат.

Светлая, тёмная и системная темы переключаются в шапке.

## Клавиатура

| Команда          | Действие                            |
| ---------------- | ----------------------------------- |
| `N`              | Новая задача                        |
| `/`              | Фокус поиска                        |
| `?`              | Справка по сочетаниям               |
| `Ctrl/⌘ + Enter` | Сохранить редактор                  |
| `Escape`         | Закрыть панель или отменить перенос |
