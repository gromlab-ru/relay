# Состояние реализации

## Прогресс: реализация 24 сентября 2026

В рабочей копии поверх `bff35fe` добавлены [ProgressService](../../../packages/core/src/application/progress/service.ts),
шесть предметных обработчиков и отдельных схем Contracts, контроллер `/progress`, SDK,
local/HTTP Backend, CLI/MCP. [Контракт](../../reference/PROGRESS.md).
Фактическое выполнение учитывает критерии и транзитивные обязательства задач; прежние
блокеры и продуктовый каскад используют те же правила. Колонки автоматически не меняются.

Web читает серверные показатели вместо подсчёта `done`: продуктовая цель показывает
готовность, причины и переходы, редактор задачи — фактическое выполнение; приложения —
раздельные счётчики. Чтение под блокировкой Workspace, страницы версионированы, итоги полные.
Прогресс не пишет данные/связи, формат хранения не изменён. Производительность отложена;
полные чтения и существующие проекции каталога сохранены. Планы ещё не реализованы.

Core: 152/152, REST: 35/35, CLI: 37/37, MCP: 11/11; типизация и сборки прошли.
Браузерная приёмка выполнена на временной базе, обе темы и четыре ширины; результаты и ограничения —
в [досье реализации](../../work/progress/README.md), исходное [ТЗ](../../../PROGRESS-SPEC.md).

## Планирование: сверка 24 сентября 2026

На `bff35fe` выполнена статическая сверка раздела «Планы»:

- Маршрут `/projects/:project/plans` подключает
  [PlansScreen](../../../apps/web/src/compositions/screens/plans/plans.screen.tsx)
  с единственным состоянием «В разработке».
- В [реестре видов](../../../packages/contracts/src/entities.ts) нет плана и этапа;
  [контракт задачи](../../../packages/contracts/src/entities/board-task.ts) не содержит
  участия в планировании. Предметных операций планов в Core, REST/SDK, CLI и MCP не найдено.
- В Web сохранились схема и компоненты прежнего прототипа `product-work-list` /
  `PRODUCT_WORK_SCHEMA`. Внешних потребителей виджета в `apps/web/src` не найдено;
  [адаптер постоянного продукта](../../../apps/web/src/domains/product-demo/helpers/create-product-view.ts)
  возвращает `work: []`. Эти остатки не являются действующей реализацией планирования.

Пользовательская модель и вопросы: [направление](../../product/DIRECTION.md#связь-продукта-с-работой),
[досье исследования](../../work/planning/README.md). Запуск UI и сквозных сценариев
в этой сверке не выполнялся.
