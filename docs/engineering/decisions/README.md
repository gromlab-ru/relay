# Технические решения

Здесь сохраняются причины устойчивого устройства. Решение объясняет контекст,
выбор, последствия и альтернативы, если они действительно рассматривались.
История конкретного исполнения остаётся в `work`.

- [JSON-хранение и разделение форматов продукта](product-storage.md).

Новые решения добавляются по существу изменения; отсутствие отдельного документа
не является поводом выдумывать историю принятия решения.
