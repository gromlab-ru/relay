# Критерии приёмки продукта

Это программа проверки ожидаемого поведения, не отчёт о её выполнении.
Результаты и состояние кода записываются в [досье работы](../../../work/README.md).

| Сценарий                                     | Ожидаемый результат                                                                    |
| -------------------------------------------- | -------------------------------------------------------------------------------------- |
| Открыть новый проект                         | Пустой продукт без демонстрационных данных, доступно создание содержания               |
| Создать паспорт, фичу, сценарий и приложение | Постоянные ID, тексты и принадлежность сохраняются и читаются через разные интерфейсы  |
| Переименовать запись                         | Ссылки, сценарии и контракты сохраняют идентичность                                    |
| Выбрать сценарий приложения                  | Есть общий контракт фичи; соседние сценарии не включаются автоматически                |
| Сохранить невалидный состав                  | Нет частичных изменений других вкладов                                                 |
| Подтвердить все актуальные вклады            | Непустой сценарий и полный состав фичи получают готовность по общим правилам           |
| Изменить требования готового контракта       | Устаревание видно; требуется новое подтверждение                                       |
| Подтвердить один контракт                    | Другие устаревшие контракты не подтверждаются автоматически                            |
| Снять и вернуть участие                      | ID контракта и ранее созданные ссылки сохраняются                                      |
| Связать документ с несколькими областями     | Одна запись, независимые связи, обратные выборки без копий                             |
| Создать ссылку на неизвестную цель           | Понятная ошибка, документ не записан частично                                          |
| Обновить устаревшую ревизию                  | Конфликт, прежняя запись сохранена, ввод доступен для исправления                      |
| Повторить запись после потери ответа         | Исходный результат, без повторного изменения; другой запрос под тем же ключом отклонён |
| Дочитать список                              | Продолжение сохраняет фильтры; пользователь различает страницу и полный результат      |
| Превысить бюджет контекста                   | Явная ошибка и способ сузить запрос                                                    |
| Сменить проект                               | Нет данных, черновиков или результатов другого проекта                                 |
| Прочитать повреждённое хранилище             | Ошибка, а не пустой продукт                                                            |
| Мигрировать старый формат                    | Неизменные тексты, идентичность и история; прерванный перенос возобновляется           |

В CLI проверяются текст и JSON отдельно. В MCP — discovery, содержательный и
структурированный ответы. В Web — навигация, черновики, ошибка сети, конфликт,
клавиатура и узкий экран по [контракту интерфейса](../../applications/web/PRODUCT.md).
