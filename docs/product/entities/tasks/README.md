# Задачи и поручения

Задача — конкретная работа на продуктовой, прикладной или инфраструктурной доске.
Она содержит однострочный заголовок, Markdown-описание, колонку и связи.
Постоянный ID сохраняется при переносе; ключ отражает доску, прежние ключи разрешаются.

Канонические правила: [канбан](KANBAN.md). [Точный контракт](../../../reference/KANBAN.md)
описывает хранение, ревизии, повтор, пагинацию и REST. [Движок сущностей](../../../reference/ENTITIES.md)
даёт единый доступ по ключам/ID; [граф](../../../reference/GRAPH.md) — контекст и пути.

- Родительство задаёт декомпозицию: незавершённые подзадачи блокируют завершение родителя.
  Явные зависимости задают дополнительный необходимый порядок результатов.
- Только `done` удовлетворяет зависимость; отмена не считается выполнением.
- Продуктовые цели связывают работу с фичей, сценарием или реализацией.
- Завершение задачи не подтверждает готовность продукта автоматически.
- Ревизия защищает запись от потери чужих изменений; requestId обеспечивает повтор.

Прежняя числовая модель удалена. Планы, релизы, обзор и история Web находятся в разработке.
