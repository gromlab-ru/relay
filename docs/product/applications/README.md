# Приложения Relay

Каждый раздел задаёт назначение, сценарии и ожидаемое поведение приложения.
Точный синтаксис операций принадлежит справочникам; состояние реализации — инженерной библиотеке.

- [CLI](cli/README.md) — терминальный интерфейс человека и автоматизации.
- [Server](server/README.md) — общие данные, HTTP API, события и поставка Web.
- [Web](web/README.md) — наблюдение и редактирование памяти проекта.
- [MCP](mcp/README.md) — предметные инструменты для агентских клиентов.
- [Playground](playground/README.md) — использование текущего Relay на примерах.

Все приложения участвуют в [общих возможностях](../CAPABILITIES.md), а не создают
независимые модели продукта. [Технические владельцы и покрытие](../../engineering/implementation/applications.md).
