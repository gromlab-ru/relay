# Иллюстрации документации

`overview.png` и `plans.png` — обзор проекта и план работ в Relay 0.2.0,
подготовленные для корневого [README](../../README.md). Снимки сделаны в отдельной
headless-сессии на временном демонстрационном проекте Atlas. Все задачи, результаты
и состояния в этом проекте — иллюстративные данные, а не отчёт о реальной разработке.

Исходное разрешение — 1440 × 1000; тёмная тема. Используется настоящий интерфейс
без подмены элементов страницы. При обновлении сохраняйте читаемость текста
и проверяйте, что снимки соответствуют текущим возможностям продукта.

`board.png` — предыдущий снимок веб-доски Tasks от 14 сентября 2026 года,
на демопроекте из 190 задач; разрешение 1440 × 1000.
