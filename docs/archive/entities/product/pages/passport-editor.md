# Заполнение и редактирование паспорта

> Архив прототипа. Действующий [контракт Web](../../../../product/applications/web/PRODUCT.md).

[Сущность «Продукт»](../README.md) → Редактор паспорта

**Адрес:** `/projects/:project/product/passport/edit`.

Одна форма заполняет отсутствующий паспорт и изменяет существующий. Пользователь не создаёт
несколько паспортов и не выбирает паспорт по ID.

## Поля

| Поле                | Смысл                                               | Обязательность |
| ------------------- | --------------------------------------------------- | -------------- |
| Название            | Имя разрабатываемого продукта                       | Да             |
| Краткий смысл       | Одна фраза для быстрого знакомства                  | Да             |
| Описание в Markdown | Цельное описание назначения, пользователей и границ | Да             |

Заголовок страницы — «Редактирование паспорта». У формы нет полей готовности, состава приложений
или связей документа библиотеки. Предпросмотр, черновик, ошибки и конфликт версии работают
по [общим правилам](../COMMON_BEHAVIOR.md).

## Запись и возврат

- «Сохранить» применяет только содержание паспорта; ID, фичи, приложения, документы и работа
  не пересоздаются.
- После успеха открывается `/product/passport`, показывающий подтверждённые значения.
- «Отмена» возвращает туда же; изменённый ввод удаляется только после подтверждения.
- Черновик относится к паспорту текущего проекта, а не ко всем паспортам всех проектов.

## Требования перехода

Сохранение этой формы должно сохранять поля старого паспорта, которых в форме нет.
Способ представления единого Markdown и совместимость старых операций определяется в
[D-01](../OPEN_QUESTIONS.md#d-01-продукт-и-существующий-паспорт).
Не отправлять пустые значения скрытых полей как результат их отсутствия в UI.

## Критерии приёмки

1. Нельзя сохранить пустые название, краткий смысл или описание; пробелы не обходят проверку.
2. Предпросмотр отображает введённый Markdown; ошибка записи оставляет весь ввод.
3. Параллельное изменение паспорта вызывает выбор версии, а не молчаливую перезапись.
4. После сохранения сохранились идентичность паспорта и все данные вне редактируемого содержания.
