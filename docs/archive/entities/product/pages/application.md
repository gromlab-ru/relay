# Страница приложения

> Архив прототипа. Действующий [контракт Web](../../../../product/applications/web/PRODUCT.md).

[Сущность «Продукт»](../README.md) → Приложение

**Адрес:** `/projects/:project/product/applications/:applicationId`.

## Назначение и состав

Показать, за что отвечает приложение и какие общие контракты оно реализует.
Страница содержит:

- название, краткий смысл, тип, число выбранных фич и сценариев;
- «Редактировать приложение» для общих сведений;
- свёрнутый по умолчанию блок «Назначение и границы приложения» с полным Markdown;
- дерево «Реализуемые фичи и сценарии» и действие «Выбрать фичи и сценарии»;
- [связанную работу](work.md).

Дерево показывает только подтверждённо выбранные фичи и сценарии этого приложения.
Названия берутся из общего продукта, под ними — **заголовок собственного вклада**.
Индикатор относится к вкладу приложения, а не к общей готовности сценария или фичи.

У фичи показано «Готово N из M» по выбранным сценарным вкладам. Если их нет — «Сценарии
не выбраны». Сам общий вклад в фичу при этом остаётся валидным и имеет отдельный статус.

## Действия дерева

| Действие                 | Результат                                                                           |
| ------------------------ | ----------------------------------------------------------------------------------- |
| Блок фичи / стрелка      | Раскрыть или свернуть выбранные сценарии                                            |
| Название фичи            | Открыть редактор общего вклада: `scope?feature=:featureId`                          |
| Название сценария        | Открыть редактор сценарного вклада: `scope?feature=:featureId&scenario=:scenarioId` |
| Иконка справа            | Открыть исходную фичу или её сценарий в продукте                                    |
| Выбрать фичи и сценарии  | Открыть редактор всего состава приложения                                           |
| Редактировать приложение | Открыть форму имени, назначения, типа и Markdown приложения                         |

Клик по названию или исходной ссылке не переключает раскрытие. По умолчанию фичи свёрнуты;
повторяемый параметр `open` сохраняет раскрытие в URL. «Свернуть все» доступно, если раскрыта
хотя бы одна ветка; иначе показывается «Раскрыть все». Общая строка дерева визуально совпадает
с каталогом возможностей, но действия названий различаются по смыслу.

Полный Markdown вклада читается в [редакторе состава](application-scope.md) вместе с исходным
контрактом. На этой странице под названием показывается короткий заголовок, а не весь текст.

## Состояния и возврат

- Нет участия: «Определите, что реализует приложение», пояснение и доступное действие выбора.
- Нет приложения по ID: сообщение и возврат в каталог.
- Вход из фичи раскрывает нужную ветку и показывает целевой вклад.
- Возврат из исходного контракта или редактора восстанавливает приложение, раскрытие и якорь.
- Вход из фичи/работы меняет подпись обратного действия; прямой вход возвращает в каталог приложений.

## Критерии приёмки

1. Название ведёт к редактированию вклада, иконка — к общему контракту; это разные адреса и действия.
2. Статус общего вклада не заменяется автоматически статусом исходной фичи или дочерних вкладов.
3. Переименование исходной фичи обновляет название, сохранив собственный заголовок вклада.
4. Возврат к якорю после чтения источника видим под шапкой, раскрытие сохранено.
