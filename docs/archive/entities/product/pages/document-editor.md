# Создание и редактирование документа

> Архив прототипа. Действующий [контракт Web](../../../../product/applications/web/PRODUCT.md).

[Сущность «Продукт»](../README.md) → Редактор документа

**Создание:** `/projects/:project/product/documents/new`.
**Изменение:** `/projects/:project/product/documents/:documentId/edit`.

## Содержание и свойства

В основной области находятся название, краткое описание и Markdown с предпросмотром;
в боковой — тип и связи. На узком экране области располагаются последовательно.
Внизу — состояние черновика, «Отмена» и «Сохранить документ».

| Поле             | Правило                                                    |
| ---------------- | ---------------------------------------------------------- |
| Название         | Обязательно                                                |
| Краткое описание | Необязательно; одна-две фразы для карточки                 |
| Текст документа  | Обязательный Markdown                                      |
| Тип документа    | ТЗ, описание, правила или решение; по умолчанию «Описание» |
| Связи            | Независимый множественный выбор; пустой набор допустим     |

У нового документа все текстовые поля пусты, связей нет. Редактирование загружает именно
текущий документ; его ID не редактируется. Дату обновления пользователь не вводит.

## Выбор связей

«Добавить связи» или «Изменить связи» открывает модальное окно. Оно содержит:

- ветки «Продукт» и «Приложения»;
- поиск по имени, контекстному пути и виду области;
- список независимых чекбоксов с названием, видом и родительским путём;
- количество выбранных областей, «Очистить» и «Готово».

Виды целей: продукт, фича, сценарий; приложение, реализация фичи, реализация сценария.
Отступы показывают контекст, но не означают каскадного выбора. Сценарий можно связать без
родительской фичи, а реализацию — без отдельного выбора приложения или исходного сценария.
Допустим одновременный выбор обеих веток.

Правила модального окна:

1. Чекбокс сразу меняет поле **текущей формы и её черновик**, не подтверждённый документ.
2. Смена ветки или поиск сохраняют скрытые выбранные элементы.
3. «Очистить» снимает весь набор, включая скрытые поиском области и другую ветку.
4. «Готово», крестик и Escape закрывают окно, сохраняя текущий выбор в форме. Это не отдельные
   «сохранить» и «отменить связи»; откат всей формы выполняется через «Отмена» редактора.
5. При повторном открытии поиск очищается; выбранный набор остаётся.
6. Нет совпадений: сообщение «Область не найдена» и возможность изменить запрос.
7. При закрытии возвращается фокус; `Ctrl/⌘ + Enter` внутри открытого диалога не отправляет документ.

В текущем UI варианты берутся из независимого мокового справочника. На следующем этапе
выбор строится из настоящих сущностей, а операция проверяет ссылки по [модели](../MODEL.md).
Добавить связь с ещё не объявленным вкладом не означает создать этот вклад автоматически.

## Сохранение, ошибки и возврат

- Проверяются название и Markdown; пустой краткий текст или связи не блокируют запись.
- Если ошибка текста обнаружена из предпросмотра, редактор возвращается на «Текст» и фокусирует поле.
- Сохраняются содержание, тип и полный набор связей одной записи. При изменении ID сохраняется.
- Успех открывает чтение документа и сохраняет адрес библиотеки в контексте возврата.
- Отмена создания возвращает к исходной библиотеке; отмена изменения — к чтению документа.
- Восстановление черновика, явная отмена, конфликт и ошибка записи действуют по
  [общим правилам](../COMMON_BEHAVIOR.md). Неизвестный редактируемый документ не создаётся повторно.

## Критерии приёмки

1. Можно сохранить документ без краткого описания и связей, но нельзя без названия или Markdown.
2. Выбор из обеих веток не включает родителей; поиск и закрытие модального окна не сбрасывают выбор.
3. Очистка изменяет форму, но не сохранённый документ до отправки; отмена формы возвращает исходные связи.
4. Ошибка сети, reload и конфликт сохраняют одновременно текст, тип и выбранные области.
5. После успеха видны обновлённая дата и подтверждённое содержание, возврат восстанавливает выдачу.
