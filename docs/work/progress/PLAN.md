# Этапы реализации прогресса

Основание и границы — [README](README.md); требования — [ТЗ](../../../PROGRESS-SPEC.md).

1. [x] Сверить владельцев, текущие расчёты, транспорт и потребителей; сохранить границы
       и отсутствие новых записей/связей.
2. [x] Общая проверка фактического выполнения задач: критерии, дети, зависимости,
       отмена, циклы, совместимость ремонта старых данных.
3. [x] Шесть схем и отдельных обработчиков, полные уникальные итоги, причины,
       ограниченные списки и защищённое версией продолжение.
4. [x] Контроллер, маршруты проектов, OpenAPI/SDK и общий local/HTTP Backend.
5. [x] CLI и MCP с русскими описаниями, JSON и человеческим представлением.
6. [x] Web: серверные показатели, фактическое выполнение, причины и переходы,
       сохранность черновиков, обновление через SSE.
7. [x] Core/REST/CLI/MCP, типизация/сборка/lint, браузерная приёмка.
8. [x] Справочники, продуктовые правила, состояние реализации, сборка скилла и передача.

Отложены по границам ТЗ: планы/релизы до их предметной модели, проектный овервью,
смена СУБД, инкрементальный пересчёт и нагрузочная оптимизация.
