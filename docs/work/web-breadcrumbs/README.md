# Хлебные крошки Web

**Статус: реализовано и проверено, 21 сентября 2026 года.**

## Цель и границы

По поручению пользователя добавить на всех страницах `apps/web` красивую и удобную
навигацию глубины на Mantine. Путь показывает текущую страницу и доступных родителей,
включая редакторы, создание, состояния ошибок и модальное окно задачи.

Предыдущая работа: [последовательные маршруты](../web-routing-consistency/README.md).
Исходная ветка `refactor/application-rebuild`, рабочее дерево перед началом чистое.

## Архитектурный допуск и план

Прочитаны протокол, стандарт интерфейсов, продуктовый контракт, инструкции Web,
skills React Reference / Unit Architecture / Template Generation, профиль React SPA,
правила слоёв, юнитов, зависимостей, колокации, routing, UI, компонентов, генерации,
Mantine, стилей, строгий style guide и quality. Изучены роутер и его потребители.

1. `app/router` объявляет метаданные цепочек рядом с URL через типизированный `handle`.
   Новое дерево URL или дублирующий распознаватель путей не создаётся.
2. `compositions/widgets/page-breadcrumbs` владеет общей навигационной проекцией:
   Mantine Breadcrumbs, ссылки React Router, сокращение пути и меню родителей.
   Публичные потребители — ProjectLayout, RelayScreen, TaskModal и RouteError.
   Проектная проекция читает matches и публичные доменные API; интерфейс принимает
   готовую цепочку. Внутренние компоненты остаются без фасетов, обратных импортов нет.
3. Названия сущностей читаются адресно через `domains/entities`, досок — через
   `domains/boards`, проекта — через существующий workspace. Полный снимок продукта
   ради крошек не загружается. Ошибка названия сохраняет понятную резервную подпись.
4. Общая полоса размещается в ProjectLayout; высота канбана учитывает её размер.
   Вне проекта используется та же визуальная проекция; модалка получает доступный путь.
5. Обновить карту маршрутов, продуктовый контракт, инженерное состояние и журнал
   генерации. Выполнить lint/typecheck/build, браузерную приёмку и проверки документации.

## Контракт и приёмка

- Предки — настоящие ссылки, текущий пункт — текст с `aria-current="page"`.
- Корень пути — проект; workspace, настройки, заглушки и неизвестные пути различаются.
- Редакторы и создание имеют отдельные подписи, сущности — актуальные названия.
- Нет фиктивных ссылок на отсутствующие каталоги сценариев и реализаций.
- Крошки показывают иерархию, а не историю посещений; Back/Forward и прямой URL работают.
- Узкая область сохраняет текущую страницу и доступ ко всем скрытым предкам через меню;
  длинные названия не создают горизонтальную прокрутку и доступны полностью.
- Проверяются обе темы, 1440/1024/768/390, клавиатура, сеть, черновик и внешнее обновление.
- Машинная проверка: метаданные всех маршрутов, реальные href, адресные ответы REST,
  отсутствие полного снимка на адресном просмотре. Хранилище и API не меняются;
  миграция и новая пагинация не нужны (путь ограничен глубиной маршрута).
