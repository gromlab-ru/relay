  Проверены короткие совместимые адреса сценариев, реализаций и задач, прямая загрузка
  и канонизация. В workspace проверены выбор проекта, недоступный проект и возврат через Relay.

  отсутствует запрос полного снимка продукта. Отказ резолвера сохраняет резервные подписи

- Возврат из задачи к доске закрывает окно с сохранением `q/blocked/cancelled`, Back
  открывает его снова. Возврат к каталогу фич сохраняет `?q=аудит`; Back/Forward работают,
  `performance.timeOrigin` не меняется при SPA-переходах.
- В обеих темах просмотрены снимки на 1440/1024/768/390. Полоса остаётся одной строкой;
  длинные подписи сокращаются, родители доступны в меню. Финальная CSS-правка запрещает
  сжимать текущую подпись: на 390 «Редактирование» видно целиком, переполнения страницы нет.
  Enter и стрелки работают в меню, Escape внутри окна задачи закрывает меню, сохраняет
  само окно и возвращает фокус. Полные подписи доступны через tooltip при фокусе/наведении.
- Axe страницы редактора в обеих темах и диалога задачи: 0 violations, 0 incomplete.

  обходе ранее однократно возник `AbortError: signal is aborted without reason` с RouteError.
