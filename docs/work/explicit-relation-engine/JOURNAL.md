# Журнал единственного механизма связей

## 22 сентября 2026 — исследование и допуск

- Прочитаны обязательный стандарт, протокол, библиотека, продуктовая концепция,
  интерфейсный стандарт и инструкции владельцев. Сверены ветка и незакоммиченные изменения.
- `graph/catalog.ts` вычисляет рёбра из полей продукта/задач/досок; `GraphService`
  объединяет их с постоянными рёбрами. Вычисленные рёбра не сохраняются в relations.
- `context.ts` содержит скрытое отсечение по видам. Для требуемого исследования
  любого окружения оно удаляется; profile=context остаётся совместимым именем all.
- Решено сохранить v1/v2 и постоянный source=graph, не выполнять автоматический импорт
  продуктовых данных. Явное подключение продуктовых сценариев отложено пользователем.
- Изучены Core-тесты хранения, графа, документов, удаления и истории задач, REST/CLI
  графа, каталог сущностей и потребители Web. Карточки существующих сущностей сохраняются,
  включая неинициализированный продукт и неактивные реализации.
- Новых UI-владельцев, React-компонентов или бизнес-правил не вводится; совместимая
  форма ответа сохраняется для текущего Web. План реализации и проверок — в README.

## 22 сентября 2026 — реализация единственного источника

- `GraphCatalog` теперь содержит только nodes/aliases; удалены вычисление domain-рёбер
  и повторные обходы продуктовых репозиториев. `GraphService` читает только репозиторий
  связей; `context.ts` удалён. Валидатор пакета остаётся третьим аргументом конструктора.
- Контракт source сужен до graph, profile=context оставлен совместимым именем all.
  CLI/MCP по умолчанию запрашивают полный обход. CLI объясняет диагностическое назначение
  прямой записи и показывает «Сохранённая связь Core» вместо альтернативных источников.
- SDK пересоздан закреплённым генератором 5.2.4 из OpenAPI изолированного сервера:
  101 операция, 503 модели. Скрипт `.artifacts/explicit-graph-sdk.mts`, временная база
  удалена, собственный сервер закрыт. `/tmp/opencode` оказался недоступен для записи,
  использована `.artifacts`; первая попытка URL получила объект от listen, исправлена на getUrl.
- Добавлен тест разделения продуктового линка и графа: нет ребра без mutate, связь
  переживает новый экземпляр сервиса и удаление продуктового поля; remove не отменяет
  продуктовые данные, reindex не воскрешает связь, повтор возвращает прежнюю квитанцию.
- Обновлены проверки полного контекста через документы/приложения, HTTP/CLI/MCP,
  прежние ожидания domain-рёбер и benchmark-каталог. В тесте параллельной библиотеки
  сохранены проверки продуктовых данных; ожидание проекции заменено отсутствием графовой
  записи. Для typecheck добавлено сужение существующего union через libraryCounts in page.
- Документы контракта, стандарта и состояния приведены к новой реализации. Полнота
  контекста теперь относится ко всем сохранённым связям в явных границах, не к скрытой политике.
