# Ознакомление перед прототипированием Web

**Статус: ознакомление завершено 19 сентября 2026 года.**

## Цель и границы

По поручению пользователя изучить документацию Relay перед следующими изменениями Web.
Порядок будущей работы: сначала прототип функционала в веб-приложении, после готовности —
интеграция с возможностями ядра. Конкретный функционал и критерии готовности прототипа
пока не заданы. Текущее поручение ограничено ознакомлением.

Владелец результата — библиотека `docs`: запись изученных источников и точки продолжения.
Код, API и хранилища в этой работе не меняются. Основания и проверки — в [журнале](JOURNAL.md).

## Источники и результат

Изучены обязательный протокол и правила библиотеки, единый стандарт интерфейсов,
[концепция продукта](../../product/README.md), карта возможностей, жизненный цикл,
[направление развития](../../product/DIRECTION.md), модель продукта, контракты Web,
локальные инструкции Web, [архитектура](../../engineering/ARCHITECTURE.md)
и карточки реализации продукта и приложений. Прочитана точка продолжения перестройки библиотеки.

По документации существующий продуктовый раздел уже использует постоянные данные
Core/REST. Связи новой продуктовой модели с задачами, контрольными точками и релизами
пока неполные. Этап будущего прототипирования не означает, что текущий Web работает на моках.

## Точка продолжения

- Следующий шаг: получить конкретный сценарий прототипа и критерии его готовности.
- Перед реализацией выполнить допуск из `apps/web/AGENTS.md`, определить владельцев
  изменения и границу будущего подключения к ядру.
- Блокеров для ознакомления нет. Запуск приложения и проверка поведения не выполнялись.
- Ветка: `refactor/application-rebuild`; при старте уже присутствовала большая
  незакоммиченная перестройка документации. Она сохранена.
- Собственные изменения: это досье и строка в индексе работ. Процессы не запускались.
