# Предыдущая переработка продуктового контекста

**Статус: исторические записи 19 сентября 2026 года.**

[Журнал](JOURNAL.md) перенесён из `docs/product/CHANGELOG.md`. Он сохраняет сообщения
о переработке документации и объединении веток. При инвентаризации обнаружено, что
некоторые заявленные изменения документации не соответствовали имеющимся файлам:
старое видение и постраничные спецификации оставались на месте.

Поэтому записи не используются как подтверждение текущего состояния и не переписываются
задним числом. Их полезные материалы `DIRECTION`, `LIFECYCLE` и `INTERFACE` включаются в
действующую библиотеку. Продолжение: [перестройка библиотеки](../documentation-library/README.md).
