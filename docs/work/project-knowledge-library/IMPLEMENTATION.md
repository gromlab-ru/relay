# План завершения библиотеки знаний

Статус: выполнен в границах библиотеки и прикреплений. Результаты проверок и ограничение
общего серверного прогона зафиксированы в [журнале](JOURNAL.md).
Основание — [исправленный контракт](CONTEXT-ALIGNMENT.md) и обязательный стандарт.

## Владельцы и запись

- Продуктовый документ хранит содержание, свойства и прикрепления (`links` совместимости,
  `relations` нового предметного контракта). Это продуктовые линки, не рёбра движка.
- `application/documents/link-workflow` координирует публикацию документа и явные вызовы
  `GraphService.mutate`. Его вызывает общий `ProductService.mutate` для документов.
- `storage/document-links` хранит соответствие сигнатуры линка ID ребра в
  `product/.document-links/<id>.json` и единственное долговечное намерение в
  `product/.transactions/document-links.json`. Формат служебных данных — версия 1.
- Намерение содержит подготовленную запись документа, исходные хеши файлов, разницу
  отношений, прогресс и точный выполняемый графовый пакет с ключом повтора. Сначала
  публикуется продуктовая часть, затем явно вызывается движок. Версия графа читается
  после продуктовой записи под той же блокировкой. Результат возвращается после обоих шагов.
- Workspace перед внешней операцией восстанавливает незавершённое намерение после
  существующих WAL. Вложенные вызовы используют активную общую блокировку. Это восстановление
  уже начатой записи, не импорт продуктовых полей при чтении.
- Прикладной сценарий изменяет только принадлежащие ему рёбра. Смена пояснения сохраняет
  ID, смена цели/назначения снимает прежнее и создаёт новое. Пакеты ограничены 100 операциями;
  прогресс нескольких пакетов сохраняется в общем намерении.
- Старые линки переносятся при явном сохранении документа. Совпавшее независимое
  ребро без записанного владения не присваивается молча: конфликт требует явного ремонта.
  Чтение не создаёт отсутствующих рёбер. Не относящиеся к документам сценарии не подключаются
  скрыто; полная сквозная цепочка зависит от их собственной интеграции.

## UI и архитектура Web

Прочитанные skills Unit Architecture, React Reference, генерации и REST применимы.
Фасеты, профиль, формы Mantine, доменные SWR/SDK-адаптеры и CSS-токены сохраняются.

1. «Прикреплено к» — предметные привязки, поиск и выбор без технических полей графа.
2. Просмотр графа и путей не входит в эту задачу. По уточнению пользователя от
   22 сентября библиотека предоставляет линковку документов к сущностям; бекенд
   после продуктовой записи создаёт, изменяет или снимает соответствующие связи Core.
3. Читатель: назначение, тип/черновик и раздел сразу видны; прикрепления рядом с текстом.
   На мобильном прикрепления компактно сворачиваются, не вытесняют весь текст.
4. Редактор и окна сохраняют ввод, различают локальную копию и серверный черновик.
   Изменение версии не обновляет основание полной записи без решения пользователя.
5. Обратное прикрепление доступно из фичи, сценария, реализации, приложения и задачи.
   Отказ отдельных записей виден. Отдельный просмотр контекста не добавляется.

## Проверки

Core: два сохранённых результата до чтения, повтор, сбои на границах стадий и рестарт,
идентичность рёбер при редактуре, независимые рёбра, замена/снятие/удаление, старые линки.
REST/CLI/MCP: общий сценарий, русский человеческий результат и JSON, точный повтор и CAS.
Web: собственный headless agent-browser и временные данные, обе темы и ширины
1440/1024/768/390, клавиатура, ошибки сети, конкурентные записи, SSE, a11y и визуальная оценка.
Завершение: lint/typecheck/build, профильные тесты, документация, skills:build/check,
docs:check, форматирование и diff --check. Свои процессы закрываются, продолжение фиксируется.
