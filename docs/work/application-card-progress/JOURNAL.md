# Журнал прогресса приложений

## 22 сентября 2026 — проектирование

Проверены рабочее дерево и текущая реализация. Каталог приложений пока показывает
только состав. TaskSummary содержит productLinks и column, фильтр board поддерживает
slug. completion=finished включает cancelled, поэтому для выполненных используется
именно done. Специального агрегата бизнес-задач API не имеет: выбрано постраничное
чтение сводок с проверкой версии, без загрузки Markdown и хранения списка в кеше.
Счётчики публикуются только после полного обхода, а не по первой странице.

UI остаётся у существующего экрана, данные — у board-tasks. Новых междоменных связей
нет. Изменения пользователя в канбане и domains/product не затрагиваются.

## 22 сентября 2026 — реализация

Добавлены адаптер и SWR-хук полного прогресса доски, сгенерирован внутренний компонент
application-progress. Карточка использует растянутую ссылку названия; кнопка повтора
находится вне ссылки. Проценты округляются вниз, чтобы 99,9% не становились 100%.
У двух показателей постоянные пояснения, счётчики и доступные имена; пустота отличается
от загрузки и ошибки. Продуктовый контракт и технический документ обновлены вместе с кодом.

`pnpm run lint:web`, `pnpm run typecheck:web`, `pnpm run build:web` прошли.
Vite сообщает предупреждение о существующем крупном основном чанке (>500 kB).
