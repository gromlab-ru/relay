# Восстановление подключения MCP

Статус: исправлено и проверено; общая сборка ограничена смежным рассогласованием SDK.

## Цель и границы

Устранить падение MCP при подключении клиента: отсутствует русское описание
`target` в контракте связи документа. Владелец — `packages/contracts`, потребитель —
`apps/mcp`. Исправление метаданных схемы не меняет валидацию, хранение и API.
Сценарий приёмки: подключить клиент, получить инструменты и выполнить чтение.

Связанные документы: [контракт MCP](../../product/applications/mcp/README.md),
[реализация приложений](../../engineering/implementation/applications.md).
Смежная работа: [библиотека документов](../project-knowledge-library/README.md).

## Проверки и продолжение

Добавлено русское описание `documentRelationSchema.target`. Прямой запуск исходного
MCP с конфигурацией Playground подтвердил подключение, 66 инструментов, русские
описания всех полей и чтение `projects_list`. Интеграционные тесты: 9/9.

Рабочая ветка: `refactor/application-rebuild`. В дереве есть существующие изменения
Web, Contracts, Core и документации; файл `document-library.ts` ещё не отслеживается Git.
Дальнейших действий для этого падения не требуется: перезапустить `npm run mcp`.
В смежной работе требуется синхронизация REST SDK с новыми контрактами библиотеки:
она блокирует `build:mcp` в `project-runtime`, но не запуск из исходников.
Проверочные процессы завершены. Результаты — в [журнале](JOURNAL.md).
