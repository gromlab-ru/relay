# Реализация универсальных связей

## Основание и границы

Пользователь поручил реализовать механизм и проверить восстановление связей агентом
через CLI и установку связей через Web. Согласована граница: универсальное ядро,
предметные ограничения приложений, произвольные типы/вложенности, общий граф проекта.

## Владельцы и допуск

- Core: `domain/entity-graph.ts`, `storage/graph.ts`, `application/graph` — граф, каталог
  существующих сущностей, транзакции и объясняющий обход. Без Web-зависимостей.
- Server Runtime: REST и OpenAPI над сервисом Core; Project Runtime — local/HTTP.
- CLI: команды `graph`, человеческие представления в `presentation`.
- Web: `domains/relations` — адаптер и SWR; `compositions/screens/project-relations` —
  каталог, связывание и контекст; `app/router` подключает экран, каркас даёт навигацию.
  Зависимости: композиция → domains/relations → существующий infra/tasks-api → SDK.
  Фасеты `index.ts`, браузерный профиль, обратных импортов нет.
- Прочитаны AGENTS Web, React Reference (pages, data-fetching, forms, TSX-generation,
  TypeScript и JSX), профиль React SPA и Unit Architecture (profile, units, dependencies).
  Загружены skills генерации и REST. Новые TSX создаются локальным генератором.

## Контракт первого исполняемого среза

1. Единый адрес `{kind,id}`, расширяемый тип ребра, Markdown-пояснение, авторство,
   ревизия и история. Новые отношения канонически хранятся в графе.
2. Для безопасного перехода существующие структурные отношения читаются адаптером
   из своих единственных владельцев, с явным происхождением и без копирования на диск.
   Они не выдаются за завершённую миграцию старых API. Новые произвольные отношения
   редактируются графовыми операциями; старые предметные связи — прежними операциями.
3. Атомарный JSON-агрегат графа версии 1 хранит новые рёбра, события и квитанции;
   размер ограничен до публикации. Это первая физическая схема; разбиение на файлы
   потребует версии/миграции. Отсутствующий файл означает пустой набор новых связей.
4. Общая блокировка, CAS по версии снимка, повтор requestId, атомарный пакет;
   ошибки не оставляют частичной записи. Неизвестные цели отклоняются.
5. Каталог и граф постраничны; версия охватывает сущности и связи. Контекст возвращает
   пути включения, границу глубины и продолжение. Циклы допустимы и обходятся безопасно.
6. Web предоставляет страницу связей с выбором сущностей, произвольным типом,
   пояснением, удалением новых связей и восстановлением окружения выбранной сущности.

## Проверки

- Core: циклы, произвольные пары, обратный обход, продолжение, неизвестные цели,
  конкуренция, повтор, сохранность после ошибки, изоляция проектов, диск/Markdown.
- REST/CLI: общий контракт, сгенерированный SDK, агентский сценарий по реальным командам;
  отдельно текст и JSON, ошибки и конфликт версии.
- Web: собственный headless agent-browser и временный проект, добавление/удаление,
  контекст после reload, размеры 1440/1024/768/390, темы, клавиатура и ошибки.
- Итог: typecheck/tests затронутых пакетов, lint/build Web, docs:check, форматирование,
  skills:build/check после справки CLI, git diff --check.
