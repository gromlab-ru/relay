## 21 сентября 2026 — поручение пользователя

По скриншоту новой формы критериев пользователь предложил уменьшить поля глобально
через Mantine. Проверена тема: Input/TextInput/Textarea/Select принудительно имели md;
Markdown отдельно использовал 14px, 14px padding и шесть строк. Настройки проекта
дополнительно переопределяли размер двух TextInput. Выбраны sm и компактный общий Markdown.

Браузер подтвердил уменьшение однострочного поля 42→36px. Обнаружено, что общий
font: inherit перекрывал размер шрифта Mantine у полей: заменён на font-family,
чтобы sm действительно управлял типографикой. Markdown теперь использует 13px,
отступы 10px и начальную область около 103px вместо прежних 134px.
