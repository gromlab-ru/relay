# Журнал настроек проекта

## 2026-09-20 — требования и исследование

В текущей конфигурации нет имени/slug проекта: контекст использует имя каталога,
шапка предпочитает заголовок legacy-паспорта. Реестр workspace имеет собственный ключ
регистрации, который не следует молча переименовывать при смене URL.
Пользователь подтвердил адрес по slug, случайный начальный `project-xxxx` и постоянное
серверное сохранение. ID остаётся идентичностью данных, кеша и подписки.
Изучены ближайшие владельцы и обязательные инструкции; план и проверки сохранены в README.

Уточнение пользователя: удалить создание задачи из общей шапки, оставить создание
в соответствующих разделах. Настройки размещаются рядом с переключателем темы.

Иконка по уточнению пользователя — шестерёнка (Lucide Settings).
Реализованы Core/HTTP и сгенерирован SDK: 97 операций, 427 моделей, 103 файла.
Целевые Core и HTTP тесты прошли по 2/2: совместимость, конкуренция, повтор, slug и изоляция.
Созданы экран/форма штатным генератором; разделены адрес и ID проектного контекста.
Первая проверка Web обнаружила четыре оставшихся потребителя ID после перехода ссылок
на slug; ID возвращён отдельно для операций и черновиков этих владельцев.
Временный сервер 4795: PID 1548884, данные .artifacts/project-settings-QIL1QR,
проект YKfndgyF; пользовательские данные не затронуты.
