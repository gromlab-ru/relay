# Журнал удаления сущностей

## 2026-09-21 — исследование и требования

Прочитаны обязательный протокол, правила библиотеки, контекст продукта, стандарт интерфейсов,
инструкции Web/Core/Contracts/Server runtime/SDK и обязательные frontend skills.
Рабочее дерево чистое. Проверены ProductService, EntityEngine, репозитории продукта,
досок, задач, графа и истории. Публичного удаления нет. Снятие реализации из состава
сохраняет неактивную запись и не является требуемым удалением.

Пользователь уточнил каскад вместо первоначально выбранного запрета при зависимостях:
удаляются дочерние сущности, внешние сохраняются с очисткой ссылок. Для документа
особо оговорено сохранение прикреплённых сущностей. План и сценарии закреплены в README.
Проверки реализации ещё не запускались.

## 2026-09-21 — общий механизм

Добавлены схемы предпросмотра/подтверждения и Core-сценарии каскада. Репозитории продукта,
задач и графа умеют готовить файлы до публикации. Общий WAL удаления хранит прежние хеши,
готовые значения и отдельную квитанцию; восстанавливается перед чтениями. Внешний конфликт
останавливает восстановление вместо перезаписи. Пустая доска удаляется только после её файлов.
История графа сохраняется с отзывом связей, а не физическим уничтожением журнала.
Ожидаемые сценарии вынесены в docs/product/ENTITY-DELETION.md.

`pnpm run build:core` прошла после первого этапа изменения хранения и контрактов.
Поведенческие проверки и Web ещё в работе.
