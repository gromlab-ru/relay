## Первое исполнение Core

- Переносимые схемы продукта, реализаций, досок, задач и настроек перенесены в contracts;
  Core сохраняет совместимые пути экспорта. Общие текстовые валидаторы работают без Node API.
  Повторные интерфейсы продукта заменены выводом типов из схем; проверка совместимости перенесена в Core.
- Добавлены реестр девяти видов, типизированные данные/действия, общий каталог и резолвер
  назначенных адресов. Фильтры, ключи, алиасы и история имеют версию и продолжение.
- Движок вызывает зарегистрированные обработчики под той же блокировкой; вложенный вызов
  сохраняет владение через AsyncLocalStorage. Создание задачи с целями и зависимостями атомарно.
- Задачи v3 сохраняют события; доски и настройки v2 — ключи, алиасы и точные квитанции.
  Совместимое чтение прежних форматов сохранено. Документы получают DOC-N, паспорт — PRODUCT;
  существующие ID и тексты не меняются. Реализация создаётся адресной операцией без
  переподтверждения соседних вкладов. Ключи больше не ограничены прежними префиксами вида.
- `pnpm install --offline` обновил связи workspace. Сборки contracts/Core и typecheck Core прошли.
  Четыре новых Core-сценария прошли: девять видов, ключ/ID и вложенные ссылки, смена ключа
  всех видов/алиасы/повтор, фильтры/страницы, атомарность, конкуренция и изоляция.
- Подключаются граф и REST; сквозные проверки клиентов пока впереди.
