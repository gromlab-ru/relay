# Движок основных сущностей

## Цель и статус

Реализация согласованного API для project, product, feature, scenario, application,
implementation, board, task, document завершена и проверена. Начата 20 сентября 2026 поверх `f21bf71` в ветке
`refactor/application-rebuild`. Основание — обсуждение после [графа связей](../entity-relations/README.md).

Человек и агент используют читаемые ключи. Каждая публичная ссылка принимает ключ или ID;
Core разрешает её в постоянный `{kind,id}` и выполняет предметную операцию по ID.
Смена ключа сохраняет идентичность, связи и прежние адреса. Определения видов задаются в коде.

## Владельцы и границы

- `packages/contracts`: переносимые схемы, описания девяти видов и параметры операций.
- `packages/core`: реестр, резолвер, выборки, предметные обработчики, ключи и хранение.
- Server/Project Runtime: REST/OpenAPI и одинаковое подключение local/HTTP.
- CLI/MCP/Web: представления и сценарии над общими контрактами.
- Готовность продукта сохраняет действующие правила; новый движок не вводит автоматическую
  приёмку реализации по завершению задачи. Виды старого жизненного цикла не входят в каталог.

## Приёмка

Каталог видов объясняет назначение, поля, фильтры и действия. Список записей поддерживает
поиск, объявленные фильтры, сортировку и страницы 1–100 с версией снимка. Полные данные
читаются адресно. Проверяются ключ/ID во всех ссылочных аргументах, алиасы после переименования,
коллизии, изоляция проектов, атомарность, повтор, сохранность ID/Markdown и контекст графа.
CLI проверяется в человеческом и JSON-режимах; MCP — через discovery и вызовы; Web —
через собственную headless-сессию agent-browser, lint, typecheck и сборку.
