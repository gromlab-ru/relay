# Журнал общих разделов навигации

## 22 сентября 2026 — исследование и план

Изучены протокол, документация, инструкции Web, профиль и профильные skills.
Документы сейчас подключены под ProductLayout и используют полный продуктовый снимок.
Для самостоятельной проектной ветки достаточно существующей product-snapshot boundary;
модель данных не требует изменения. Старые ссылки перенаправляются на новые в ProductLayout.
Существующий ключ черновика будет сохранён независимо от нового URL.

Название «Документы» выбрано как прямое обозначение содержимого. Состав инфраструктуры
не задан; добавляется действующая навигационная точка со статусом «В разработке».
Дополнительное поручение: обе раскрывающиеся группы первоначально закрыты;
автоматическое раскрытие по URL удаляется, подсветка активной группы сохраняется.

Проверено исходное рабочее дерево: пользовательские правки исследователя связей
не относятся к этой работе. План и критерии зафиксированы в README до реализации.

Дополнительное уточнение пользователя: «Связи проекта» также перенесены в нижнюю
группу, сразу после инфраструктуры. Содержимое исследователя связей не меняется.

## 22 сентября 2026 — реализация

Обновлены группы навигации и начальное состояние. Документы подключены отдельной
веткой проекта, ссылки из продуктовых страниц и крошки согласованы. При исследовании
обнаружена канонизация URL в ProductOutlet: она ограничена продуктовой веткой, иначе
общая библиотека была бы перенаправлена обратно в продукт. Состояния загрузки и ошибки
библиотеки получили собственные подписи. Старые ссылки сохраняются через ProductLayout.

Сгенерирован infrastructure через локальный ui-unit, адаптирован в экран-заглушку.
Ключ черновика документа сохранён с прежним `/product`, чтобы смена URL не потеряла ввод.
Продуктовый контракт, карта маршрутов, README Web и техническое состояние обновлены.
Проверки — следующий шаг.

  Сборка сообщает прежнее предупреждение о чанке больше 500 kB.
- `pnpm run docs:check` — 198 файлов, 1000 ссылок, ошибок нет; скилл — 17 файлов,
  64 ссылки, ошибок нет. `git diff --check` успешен. Prettier применён адресно.

- Переход в документы показывает пустое состояние; создание сохранило документ

- Блокировка запроса `**/product/state` дала «Не удалось прочитать документы»;
  снятие блокировки и «Повторить загрузку» восстановили каталог.
