# Цвета целей карточки в тёмной теме

## Цель и статус

Реализовано и проверено 22 сентября 2026. По скриншотам пользователя выровнять заметность меток
фич и сценариев на канбане: фиолетовый слишком насыщен, зелёный сливается с карточкой.

## Границы, владелец и план

- Владелец — вложенный `task-card` композиции `project-board`; локальный CSS Module
  оформляет и карточку, и TaskCardPreview. Потребители идут через фасеты `task-card`
  и `task-column`; импорты, публичные props и граф зависимостей не меняются.
- Прочитаны профиль `apps/web/README.md`, Unit Architecture (колокация), React Reference
  (стилизация, CSS, общий стиль и использование Mantine), обязательный протокол Web.
- Сохранить светлое оформление; в тёмном смешать светлые оттенки violet/teal с поверхностью
  карточки. Цвета текста и иконок должны иметь контраст не менее 4,5:1 к подложке.
- Человеческий сценарий: различить фичу и сценарий по цвету, подписи и иконке; прочитать
  название и `+N`. Пустые/неразрешённые цели сохраняют нейтральное оформление.
- API, хранение, миграции и пагинация не затрагиваются. Машинную сводку сверить отдельно
  от визуального результата. Новых юнитов, TSX и автотестов нет.
- Проверки: изолированная agent-browser-сессия на временной базе, обе темы и ширины
  1440/1024/768/390, контраст и клавиатурный доступ; lint/typecheck/build Web,
  docs:check, форматирование затронутых файлов и git diff --check.
