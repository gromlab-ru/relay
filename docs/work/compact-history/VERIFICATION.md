## Демо-база

Команды выполнялись из корня Relay через собранный CLI с
`--local --config apps/playground/p2p-rental/.relay/config.json`:

- `storage migrate` — выполнен явный переход, 76 сущностей сохранено.
- `storage reindex` — 145 активных связей, 216 событий связей, ревизия графа 67.
- `--format json validate` — valid=true, entities=74, boards=4, tasks=1.
- `task history list PRODUCT-1` и `task history get PRODUCT-1 2` — человеческий вывод
  содержит прежний/новый заголовок и факт изменения описания, а JSON — `contentOmitted: true`.
- Повтор `--format json storage migrate` — migrated=false, schemaVersion=2.
- Работающий dev-server прочитал обзор продукта по REST после перехода.

До миграции — 81 файл, 1 289 916 байт. Сразу после — один сегмент, 509 434 байта.
После первого проверочного обслуживания — 509 760 байт и 82 записи. Обнаружена и исправлена
пустая запись при обновлении только производных карточек; повтор reindex больше не увеличил
журнал. Служебная запись уже выполненного обслуживания оставлена как фактическая история.

Сравнение контрольных сумм подтвердило совпадение 147 файлов сущностей, отношений,
пространств ключей и конфигурации. Все 81 исходные квитанции совпали по автору, времени,
namespace/requestId/hash, результату и затронутым адресам. Старые каталоги отсутствуют.
Полный overview превышает стандартные 16 КиБ и корректно возвращает RESPONSE_TOO_LARGE;
проверка человеческого результата проводилась адресными командами истории.
