# Работы и восстановление контекста

Одна цель — одно досье, продолжаемое между сессиями. Правила ведения:
[агентский протокол](../development/PROTOCOL.md). Сначала прочитай актуальный README
работы, затем нужные события журнала; перед продолжением сверь их с рабочим деревом.

| Работа                                                        | Статус       | Результат и точка входа                                 |
| ------------------------------------------------------------- | ------------ | ------------------------------------------------------- |
| [Перестройка библиотеки](documentation-library/README.md)     | Завершена    | Структура, обязательный протокол и перенос знаний       |
| [Первое внедрение продукта](product-initial/README.md)        | Историческая | Первоначальные решения, план и проверки 18 сентября     |

Журнал разработки Relay не является пользовательской библиотекой документов в `.relay/product`.
Память демонстрационных продуктов Playground ведётся отдельно через публичные операции Relay.
