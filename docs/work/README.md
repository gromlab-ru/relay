[агентский протокол](../development/PROTOCOL.md). Сначала прочитай актуальный README
работы, затем нужные события журнала; перед продолжением сверь их с рабочим деревом.

Память демонстрационных продуктов Playground ведётся отдельно через публичные операции Relay.

- [Ключи продукта и самостоятельные реализации](product-keys/README.md) — реализовано и проверено:

- [Настройки проекта](project-settings/README.md) — реализовано и проверено: оформленная страница,

- [Множественные доски](multiple-boards/README.md) — готово к приёмке в `p2p-rental`;

- [Ознакомление перед прототипированием Web](web-prototype-orientation/README.md) — завершено;
