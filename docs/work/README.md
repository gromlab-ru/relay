# Работы и восстановление контекста

Одна цель — одно досье, продолжаемое между сессиями. Правила ведения:
[агентский протокол](../development/PROTOCOL.md). Сначала прочитай актуальный README
работы, затем нужные события журнала; перед продолжением сверь их с рабочим деревом.

| Работа                                                        | Статус       | Результат и точка входа                                 |
| ------------------------------------------------------------- | ------------ | ------------------------------------------------------- |
| [Перестройка библиотеки](documentation-library/README.md)     | Завершена    | Структура, обязательный протокол и перенос знаний       |
| [Первое внедрение продукта](product-initial/README.md)        | Историческая | Первоначальные решения, план и проверки 18 сентября     |
| [Предыдущая переработка контекста](context-rebuild/README.md) | Историческая | Записи 19 сентября, требующие сверки с текущими файлами |

Журнал разработки Relay не является пользовательской библиотекой документов в `.relay/product`.
Память демонстрационных продуктов Playground ведётся отдельно через публичные операции Relay.

## Подготовка следующих работ

- [Цели реализации по типу доски](task-board-targets/README.md) — реализовано и проверено:
  продуктовые цели либо реализации своего приложения; ссылка контекста удалена,
  Puzzle/Route и цвет различают фичу/сценарий, без боковой полосы. Ограничения общих проверок — в досье.

- [Механики карточки задачи](task-card-mechanics/README.md) — завершено после самостоятельной
  проверки пользователя: единый раздел «Подзадачи», блокировка завершения родителя детьми,
  удаление крошек из окна карточки; результаты и ограничения проверок записаны в досье.

- [Группировка досок в навигации](board-navigation-groups/README.md) — принято пользователем:
  продукт → приложения → инфраструктура, разделители без текста; проверки остановлены по поручению.

- [Хлебные крошки Web](web-breadcrumbs/README.md) — реализовано и проверено: общая навигация
  глубины, названия сущностей, адаптивное меню родителей; путь внутри окна задачи впоследствии
  удалён в работе над механиками карточки.

- [Последовательные маршруты Web](web-routing-consistency/README.md) — завершено и проверено:

- [Карта страниц и аудит роутинга Web](web-routing-audit/README.md) — аудит завершён:

  исправления выполнены в работе о последовательных маршрутах.

- [Очистка легаси по разделам Web](legacy-cleanup/README.md) — реализована и проверена:
  удалены прежняя доска и скрытые страницы, обзор/планы/релизы/история заменены заглушками;
