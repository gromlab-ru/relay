## 2026-09-20 — Уточнение каталога Web

По просьбе пользователя раскрытие веток каталога фич исключено из URL: оно не должно
запускать навигацию и мерцание. Владелец — domains/product, личное UI-состояние сохраняется
в браузере отдельно по постоянному ID проекта, независимо от slug. Это не меняет требования
продукта и не создаёт общую настройку для всех пользователей. Поисковое раскрытие временное
и не перезаписывает обычное дерево; поиск и фильтры сохраняют собственный URL-контракт.
Проверки браузером и форматирование этого уточнения ещё предстоят.

планов; короткий маршрут оставлен как перенаправление. Проверяется принадлежность фиче.
