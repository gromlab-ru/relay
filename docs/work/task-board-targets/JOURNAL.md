# Журнал: цели реализации по доске

## 21 сентября 2026 — исследование и допуск

Прочитаны обязательные источники, skills и профиль Web; рабочее дерево чистое.
Текущий `task-context` предлагает три режима и любое приложение, не получает доску.
Core проверяет наличие цели и активность, но не тип доски. Каталог поддерживает
приложение, однако не разделяет реализации фич и сценариев до пагинации.

Зафиксирован план в README. Сохраняем UI и дисковую схему, дополняем общий инвариант
Core и фильтр каталога. Адресная загрузка доски задачи исключает зависимость от
первой страницы каталога или фоновой доски модального окна. Старые связи не удаляются
автоматически; несовместимый перенос отклоняется до записи.

Явная замена набора проверяет весь остаток; правка текста не ломается на старых данных.

test/board-targets.test.ts test/board-tasks.test.ts` — 18/18 успешно. Проверены матрица,
чужое приложение, ревизии, повторы, перенос, снятые цели, старые записи и пагинация.

ограничивается applicationId и видом имплементации. Поиск больше не меняет тип
по префиксу ключа. Состояние выбора сбрасывается при смене доски, редактор текста сохраняется.
Продуктовые и технические контракты актуализированы вместе с кодом.
