# Журнал перестройки библиотеки

## 2026-09-19 — Исходное состояние и решение о структуре

- Основание: поручение пользователя и уточнение обязательности документации при любых действиях агента.
- Прочитаны единый стандарт, продуктовый обзор, модель/готовность прототипа, действующий
  справочник продукта, архитектура, README пяти приложений и локальные инструкции.
- Обнаружено: актуальные вставки о постоянной модели соседствуют с ручной готовностью моков;
  новый журнал заявляет удаление прежних материалов, которые фактически присутствуют.
- Решение: сохранить исходные материалы в архиве, заново сформировать действующие точки входа;
  историю не переписывать как подтверждение текущего кода.
- Технические справочники остаются по стабильным адресам `docs/reference`: на них опираются
  поставка и скилл. `engineering` собирает технический контекст через ссылки.
- Добавлены протокол всех видов работ, правила библиотеки, досье этой работы и индекс.
- Проверено исходное состояние `git status --short` и имя ветки. Прикладные проверки ещё не запускались.
- Следующее действие: перенос исторических материалов и создание актуальных спецификаций.
