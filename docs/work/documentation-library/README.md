# Перестройка библиотеки знаний Relay

**Статус: завершена 19 сентября 2026 года.**

## Цель и поручение

Пользователь поручил превратить разрозненную документацию в библиотеку знаний о Relay:
ожидаемые возможности, описание CLI/Server/Web/MCP/Playground, фактическая реализация и
технические журналы для восстановления контекста. Протокол обязателен при любых работах агента.

## Границы и владельцы

Владелец — `docs`, обязательная точка входа — корневой `AGENTS.md`. Меняются документация,
навигация и расположение исторических материалов. Продуктовые операции не изменяются.
Существующие незакоммиченные документы учитываются как источники, а не удаляются как мусор.

Контракт библиотеки: один владелец факта, отдельные требования/реализация/история,
русский Markdown, относительные проверяемые ссылки. План: [PLAN.md](PLAN.md).
Действующие инструкции: [протокол](../../development/PROTOCOL.md),
[правила библиотеки](../../development/DOCUMENTATION.md),
[единый стандарт](../../development/INTERFACE-STANDARD.md).
