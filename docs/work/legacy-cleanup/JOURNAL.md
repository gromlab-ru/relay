# Журнал очистки легаси

## 20 сентября 2026 — начало и уточнение границ

- Прочитаны обязательные документы и инструкции владельцев; рабочее дерево чистое,
  ветка `refactor/application-rebuild` синхронна upstream по локальному status.
- Пользователь уточнил: включить отключённые страницы, сохранить workspace и режимы,
  не считать самостоятельные механики легаси только по отсутствию экрана.
- В роутере найдены скрытые `passport`, `knowledge`, `activity`; catch-all открывал
  прежнюю доску. Новый канбан динамически открывал старый экран по числовому ID.
- Старые страницы используют `domains/lifecycle` и `domains/tasks`. Новый продукт
  использует `domains/product` и адаптер `product-demo`; последний нельзя удалять
  по названию: он обслуживает действующие страницы продукта.
- `application/entities` использует только новые сущности; граф дополнительно проецирует
  `legacy-task` и `lifecycle-*`. Удаление этих проекций не означает удаления движка графа.
- Общий индикатор SSE импортируется из старого домена задач: требуется сохранить
  наблюдение соединения у действующего владельца при удалении старых выборок.
- Архитектурный допуск: прочитаны актуальные публичные SKILL.md и применимые references,
  профиль Web, составлен план. Установленных локальных skills в проекте нет;
  использованы канонические публичные источники без изменения окружения.

Фактические проверки пока ограничены чтением кода и `git status --short --branch`.

## 20 сентября 2026 — удаление Web-проекций

- Обзор, планы, релизы и история заменены состояниями «В разработке» в существующих
  экранных владельцах. Удалены скрытые страницы и прежний канбан с редакторами.
- Удалены старые домены задач и жизненного цикла. Индикатор соединения перенесён
  в `domains/project`: используется тот же транспорт SSE, без прежних выборок.
- Убраны навигация прежней доски, скрытые пункты и catch-all на канбан. Прямые адреса
  нового канбана сохраняются; числовой ID больше не загружает старый экран.
- Продуктовый контракт Web актуализирован сразу; прочие справочники требуют сквозной
  сверки после удаления backend. Компиляция пока не проверена, очистка потребителей продолжается.

## 20 сентября 2026 — сквозное удаление прежней модели

- Удалены Core-службы числовых задач, комментариев/отчётов этих задач и прежних документов
  жизненного цикла. Удалены их контроллеры, схемы OpenAPI, DTO и backend-операции CLI/MCP.
- Проверка целостности сохранена: читает каталог действующих сущностей, проверяет канбан
  и граф. История/квитанции действующих сущностей и миграции продукта/графа сохранены.
- Удалена только специализированная миграция UUID/числовых задач и её проверки маркеров
  в классе хранилища `Workspace`. Регистрация workspace, режимы local/workspace, выбор
  транспорта, конфигурационные схемы и блокировки не менялись.
- SSE больше не сканирует старые записи. Общие уведомления мутаций сохраняются для
  действующих POST/PATCH/PUT/DELETE; восстановление после ошибки инициирует перечитывание.
- В обоих каталогах Playground `.relay` найдены только конфиги: прежних данных для
  удаления здесь нет. Конфигурации и продуктовые ТЗ не изменены.
- Первые попытки Core `tsc -p tsconfig.json --noEmit` и Web `typecheck` не прошли:
  отсутствуют workspace-зависимости (`@relay/typescript-config`, Contracts/SDK) и CodeMirror.
  Это ещё не предметная проверка изменений. Окружение Node 24.18.0, pnpm 11.18.0;
  следующий шаг — `pnpm install --frozen-lockfile` и повтор после генерации SDK.
