# Скиллы Relay

[Документация](../README.md) → Разработка → Скиллы

## Скилл продукта

[`skills/relay-cli`](../../skills/relay-cli/SKILL.md) содержит самостоятельные инструкции
по local/workspace, подключению к серверу, назначению задач, отчётам и восстановлению.
Материалы ролей находятся в `reference` внутри скилла.

```bash
npx skills add gromlab-ru/relay --skill relay-cli
npx skills add gromlab-ru/relay --skill relay-cli --agent opencode
```

После установки в OpenCode перезапустите его для обнаружения скилла. Установщик
Skills требует Node.js 22.20+, рекомендуется 24. Пакеты Relay поддерживают Node.js 22+.

## Скиллы разработки

Внешние скиллы перечислены в [skills-lock.json](../../skills-lock.json).

```bash
pnpm run skills:install
```

Команда восстанавливает внешний набор в `.agents/skills`. Весь каталог исключён
из Git, включая локальные дополнения. Исходники продуктового скилла принадлежат
`skills/relay-cli`; редактировать нужно их.

## Версионирование

- `skills/relay-cli/**` — исходники продукта, входят в Git.
- `skills-lock.json` — источники скиллов разработки.
- `.agents/skills/**` — установленные копии, исключённые из Git.

## Изменение и проверка

```bash
pnpm run docs:check
npx skills@1.5.26 add ./skills/relay-cli --list
```

Проверка документации отдельно проверяет ссылки относительно корня скилла.
Установочные проверки выполняйте во временном проекте, чтобы не менять lock-файл
рабочего репозитория. Основной SKILL.md должен оставаться компактным и содержать
все необходимые шаги начала работы.
