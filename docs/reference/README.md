# Точные справочники

Справочник определяет синтаксис и формат действующего интерфейса. Продуктовый смысл
описан в [product](../product/README.md), технические владельцы — в
[engineering](../engineering/README.md). Адреса справочников сохраняются для потребителей
и распространяемого скилла.

| Контракт                               | Документ                                    |
| -------------------------------------- | ------------------------------------------- |
| Команды и параметры                    | [CLI](CLI.md)                               |
| REST, OpenAPI и SSE                    | [API](API.md)                               |
| Инструменты агентов                    | [MCP](MCP.md)                               |
| Конфиги, окружение и приоритеты        | [Конфигурация](CONFIGURATION.md)            |
| JSON-ответы, лимиты, пагинация         | [Вывод](OUTPUT.md)                          |
| Человеческое представление             | [Терминал](TERMINAL.md)                     |
| Ошибки и восстановление                | [Коды ошибок](ERRORS.md)                    |
| Хранилище задач                        | [Формат](FORMAT.md)                         |
| Продуктовые операции и хранение        | [Продукт](PRODUCT.md)                       |
| Структура пользовательского содержания | [Продуктовые материалы](PRODUCT-CONTENT.md) |
| Проекции и подсчёты задач              | [Обзор](OVERVIEW.md)                        |

Существующая [модель задач](../concepts/TASKS.md) поясняет семантику статусов,
зависимостей, автора и контекста, не дублируя синтаксис CLI.
