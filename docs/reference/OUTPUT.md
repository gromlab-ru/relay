# JSON, текст и пагинация CLI

## Форматы и конверты

Человеческий вывод по умолчанию — таблицы, карточки и Markdown. `--format json`
возвращает `{ok:true,data,meta?}` без ANSI. Ошибка: `{ok:false,error:{code,message,details?}}`
и ненулевой код процесса. `meta.project` сохраняет выбранную регистрацию.
Справка и версия текстовые. `output.format` задаёт начальное значение формата.

Квитанция канбана содержит ID, ключ, ревизию, действие и requestId. Полный Markdown
передаётся строкой, на диске кодируется массивом строк. Не разбирайте человеческий
текст как машинный протокол. [Терминал](TERMINAL.md), [MCP](MCP.md#ответы-и-ошибки).

## Страницы

Доски, задачи, сущности и граф используют offset/limit, total, nextOffset и версию снимка.
Сохраняйте проект, фильтры и версию при продолжении. Конец — nextOffset:null.
`--version` используется канбаном; граф и сущности принимают `--snapshot-version`.
Изменение снимка требует начать чтение заново. Продуктовые списки также возвращают nextOffset.

Реестр проектов использует `--limit`, `--cursor`, `--all` и meta.hasMore/meta.nextCursor.
Курсор не переносится между проектами и фильтрами.

## Байтовый бюджет

`--max-bytes` принимает 1024–134217728 байт; по умолчанию 16384. Учитывается полный
UTF-8 ответ выбранного формата. Большой неделимый результат возвращает RESPONSE_TOO_LARGE.
Уменьшите страницу, читайте запись адресно или увеличьте бюджет.
Не считайте сокращённый ответ полным; проверяйте признаки продолжения.

## Ограничения хранения

Бюджет ответа не меняет лимиты записи. Точные ограничения принадлежат [канбану](KANBAN.md),
[продукту](PRODUCT.md) и [графу](GRAPH.md). HTTP-тело ограничено 1 МиБ.
[Примеры автоматизации](../guides/AUTOMATION.md).
