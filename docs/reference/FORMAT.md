# Формат данных Relay

Точные схемы принадлежат владельцам данных:

- [Продукт](PRODUCT.md#json-хранилище): `.relay/product`, ключи, реализации, документы
  и Markdown массивами строк.
- [Доски](BOARDS.md): `.relay/boards/<slug>/board.json`.
- [Задачи канбана](KANBAN.md): `.relay/boards/<slug>/tasks/<id>.json`, постоянный ID,
  текущий ключ и алиасы, ревизии, события и квитанции повторов.
- [Связи](GRAPH.md#запись-и-хранение): текущие отношения, события, квитанции,
  производные индексы и восстановление составной публикации.
- [Конфигурация](CONFIGURATION.md): настройки проекта и отдельный реестр workspace.

Хранилища действующих сущностей не объединяются с прежними числовыми задачами.
Их поддержка удалена. Блокировки и runtime остаются общей инфраструктурой;
`storageDir` и режимы подключения сохраняют прежний контракт.

Перед ручной правкой или Git-слиянием сохраните исходное состояние; после выполните
`relay-cli validate`. Чтение повреждённых действующих данных не подменяется пустым списком.
Обновление форматов: [миграция](../guides/MIGRATION.md).
