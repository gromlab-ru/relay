# Ошибки и коды завершения

[Документация](../README.md) → Справочники → Ошибки

## Коды процесса CLI

| Код | Значение                                                     |
| --- | ------------------------------------------------------------ |
| `0` | Успех                                                        |
| `2` | Параметры, ввод или конфигурация                             |
| `3` | Объект или файл не найден                                    |
| `4` | Конфликт ревизии, назначения, графа, миграции или блокировки |
| `5` | Повреждение данных, ошибка ввода-вывода или HTTP-транспорта  |

HTTP-код ответа сервера и код завершения CLI — разные значения. API передаёт
`error.exitCode` для ошибок Core; CLI сохраняет поведение локальных команд.
JSON-форма ошибки описана в [выводе](OUTPUT.md#форматы-и-конверты).

MCP сохраняет коды прикладных ошибок в `structuredContent.error.code` и возвращает
`isError: true`; сам процесс продолжает обслуживать запросы. Ошибки протокола — JSON-RPC errors.

## Ввод и настройки

| Код ошибки                                                 | Причина и действие                                                                                    |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| `CONFIG_NOT_FOUND`                                         | Укажите `--config` или инициализируйте новый проект                                                   |
| `PROJECT_REQUIRED`                                         | Передайте имя из реестра: CLI-префикс/`--project` или поле `project` MCP                              |
| `PROJECT_NOT_FOUND`                                        | Проверьте `projects list` / `projects_list` и выбранный реестр; код CLI 3                             |
| `PROJECT_EXISTS`                                           | Для замены подключения используйте `--replace` / `replace: true`; код CLI 4                           |
| `REGISTRY_REQUIRED`                                        | Именованный доступ и регистрация требуют конфиг проектов; для прямого проектного конфига опустите имя |
| `PROJECT_CONFIG_REQUIRED`                                  | Запись реестра должна ссылаться на проектный конфиг, а не на другой реестр                            |
| `LOCAL_CONFIG_REQUIRED`                                    | Для локальной операции задайте `path` или `config`; одного URL недостаточно                           |
| `MCP_STOPPING`                                             | Дождитесь перезапуска MCP и переподключите клиент                                                     |
| `ACTOR_REQUIRED`                                           | Для записи нужен `--actor` или `RELAY_ACTOR`                                                          |
| `ALREADY_INITIALIZED`                                      | Конфиг уже существует; используйте его или другой путь для нового проекта                             |
| `INVALID_ARGUMENT`, `VALIDATION_ERROR`                     | Исправьте аргументы по `details`, схеме и `--help`                                                    |
| `INVALID_CONFIG`                                           | Сервер не может открыть некорректный конфиг; исправьте JSON и значения                                |
| `INVALID_ID`                                               | Нужен положительный безопасный числовой ID задачи или корректный ID записи                            |
| `TITLE_REQUIRED`, `EMPTY_UPDATE`                           | Укажите название новой задачи или хотя бы одно изменяемое поле                                        |
| `CONFLICTING_OPTIONS`                                      | Выберите один источник текста, названия или очистки поля                                              |
| `INPUT_SOURCE_REQUIRED`, `STDIN_ALREADY_USED`              | Задайте текст/файл/stdin и используйте поток только для одного поля                                   |
| `INPUT_TOO_LARGE`                                          | Уменьшите входной текст до лимита поля                                                                |
| `UNKNOWN_FIELD`, `UNKNOWN_STATUS`, `INVALID_REVIEW_STATUS` | Проверьте поле, конфиг статусов и неконечность статуса проверки                                       |
| `INVALID_DATE`, `INVALID_CURSOR`                           | Исправьте дату; для курсора повторите исходные фильтры или начните чтение заново                      |
| `RESPONSE_TOO_LARGE`                                       | Выберите поля, постраничное чтение или больший `--max-bytes`                                          |

## Объекты и конкурентность

| Код ошибки                                                          | Причина и действие                                                        |
| ------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `TASK_NOT_FOUND`, `COMMENT_NOT_FOUND`, `LOG_NOT_FOUND`, `NOT_FOUND` | Проверьте выбранную базу, ID задачи/записи и путь файла                   |
| `TASK_ASSIGNED`                                                     | Другой агент уже занял задачу; перечитайте очередь                        |
| `TASK_BLOCKED`                                                      | Откройте `links` и дождитесь успешного завершения зависимостей            |
| `TASK_NOT_READY`                                                    | Статус не входит в `readyStatuses`                                        |
| `ASSIGNEE_MISMATCH`                                                 | Освобождается чужая задача; оркестратор может явно использовать `--force` |
| `REVISION_CONFLICT`                                                 | Перечитайте карточку и согласуйте изменения с новой ревизией              |
| `IDEMPOTENCY_CONFLICT`                                              | Тот же ключ уже использован с другим автором или содержимым               |
| `STORAGE_BUSY`                                                      | Другая операция держит блокировку; повторите после её завершения          |
| `LOCK_LOST`                                                         | Владение блокировкой потеряно; перечитайте состояние перед повтором       |
| `BOARD_CHANGED`, `RANK_CONFLICT`                                    | Порядок или снимок доски изменился; обновите данные перед переносом       |

## Целостность и миграция

| Код ошибки                             | Причина и действие                                                           |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| `DEPENDENCY_CYCLE`, `PARENT_CYCLE`     | Изменение образует цикл; пересмотрите соответствующие связи                  |
| `MISSING_REFERENCE`, `DUPLICATE_VALUE` | В графе отсутствует ссылка или повторяются значения                          |
| `INVALID_DATA`, `VALIDATION_FAILED`    | Проверьте диагностику `validate`, JSON, имена файлов и вложенные записи      |
| `TASK_TOO_LARGE`                       | Полный документ превышает 16 МиБ; изменение не сохранено                     |
| `ID_EXHAUSTED`                         | Невозможно выделить следующий безопасный числовой ID                         |
| `MIGRATION_REQUIRED`                   | Нужен явный `--local migrate` выбранной базы                                 |
| `MIGRATION_IN_PROGRESS`                | Повторите прерванный `migrate` с тем же конфигом                             |
| `MIGRATION_CONFLICT`                   | Состояние публикации миграции изменилось; проверьте журнал и резервную копию |
| `IO_ERROR`                             | Проверьте доступ к файлам, свободное место и исходную диагностику            |

Проверка `validate` может объединять нарушения графа в `VALIDATION_FAILED` с кодом `5`.
Коды внутри её `details` описывают отдельные нарушения.

## HTTP-режим

| Код ошибки                              | Причина и действие                                                                       |
| --------------------------------------- | ---------------------------------------------------------------------------------------- |
| `LOCAL_ONLY`                            | Для `init`/`migrate` при настроенном HTTP укажите `--local` и нужный конфиг              |
| `SERVER_UNAVAILABLE`                    | Проверьте запуск сервера и URL; восстановление — через тот же сервер или явный `--local` |
| `SERVER_INCOMPATIBLE`                   | Обновите и перезапустите сервер с поддержкой `cli-http-v1`                               |
| `INVALID_SERVER_RESPONSE`, `HTTP_ERROR` | Проверьте, что URL указывает на совместимый Tasks API                                    |

После неподтверждённого добавления сохраняйте `error.details.requestId`.
Повтор отчёта с прежним автором и содержимым описан в [оркестрации](../guides/ORCHESTRATION.md#повтор-отчёта).
Диагностика по пользовательским симптомам — [частые вопросы](../TROUBLESHOOTING.md).
