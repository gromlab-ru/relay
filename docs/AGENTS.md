# Сопровождение библиотеки Relay

Владелец этой области — документация продукта и процесса разработки Relay.
Прочитай [протокол](development/PROTOCOL.md), [правила библиотеки](development/DOCUMENTATION.md)
и инструкции ближайшего владельца кода, если документ описывает его реализацию.

- Сначала найди канонический документ; исправляй его, а не создавай конкурирующее описание.
- Различай ожидаемое поведение, факт реализации, результат проверки и историческую запись.
- Перенос сохраняет содержание, происхождение и работоспособность ссылок. Противоречия
  разрешай по источникам; неизвестное обозначай явно.
- Журнал ведётся и при изменении самой документации. Факты не восстанавливаются выдуманными датами.
- Приёмка: навигация человеком, соответствие содержания источникам, `pnpm run docs:check`,
  форматирование изменённых файлов и проверка скилла, если затронуты его источники.
