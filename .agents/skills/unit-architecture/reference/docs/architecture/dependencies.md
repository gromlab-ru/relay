# Зависимости

Зависимости Unit Architecture строятся между юнитами, а не между отдельными файлами.

## Свёрнутый граф

Каждый импорт определяется через ближайших владельцев исходного и целевого файлов.

```text
Файл A принадлежит Unit A
Файл B принадлежит Unit B
import A → B создаёт Unit A → Unit B
```

Импорты внутри одного юнита сворачиваются во внутреннюю реализацию. Вложенный юнит является отдельным узлом.

## Публичный путь

Межюнитный импорт выполняется только через объявленный фасет целевого юнита. Импорт внутреннего файла является глубоким независимо от того, разрешено ли направление между слоями.

```ts
// Допустимо
import { getProducts } from '@/domains/products'

// Недопустимо
import { getProducts } from '@/domains/products/libs/get-products'
```

`import type` и реэкспорт также создают архитектурную зависимость.

## Матрица слоёв

| Исходный слой | Допустимые целевые слои |
|---|---|
| `app` | `app`, `compositions`, `domains`, `infra`, `ui`, `shared` |
| `compositions` | `compositions`, `domains`, `infra`, `ui`, `shared` |
| `domains` | `domains`, `infra`, `ui`, `shared` |
| `infra` | `infra`, `ui`, `shared` |
| `ui` | `ui`, `shared` |
| `shared` | `shared` |

Разрешённая связь может пропускать промежуточные слои. Матрица ограничивает направление, но не переносит ответственность.

Связи `app → domains`, `app → infra` и `app → ui` позволяют инициализировать и подключать готовые возможности, например глобальные Providers. Они не разрешают хранить их реализацию в `app`. Продуктовый интерфейс маршрута собирается в `compositions`, даже если все его импорты формально разрешены для `app`.

## Same-layer зависимости

Юниты одного слоя могут зависеть друг от друга через фасеты, если общий граф остаётся ацикличным. Если два юнита постоянно меняются вместе и образуют взаимные связи, необходимо пересмотреть ответственность и колокацию.

## Вложенные юниты

Containment задаёт дополнительное направление:

```text
Parent → Child
```

Ребёнок не импортирует родителя, предков или соседних детей. Родитель передаёт ему данные и callbacks через контракт ребёнка и координирует взаимодействие детей.

## Запрет циклов

Полный свёрнутый граф юнитов не содержит циклов.

```text
A → B → C → A   # Недопустимо
```

Проверка отдельных файлов недостаточна: цикл может проходить через разные файлы каждого владельца.

## Смысл зависимости

Формально разрешённый импорт может скрывать неверного владельца. Например, `compositions` может зависеть от `infra`, но не использует HTTP transport для реализации предметной загрузки Products. Такая операция принадлежит `domains/products`, а композиция получает готовый доменный API.
