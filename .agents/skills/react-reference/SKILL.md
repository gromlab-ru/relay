# React Reference

Этот skill содержит правила команды для разработки React SPA. Он помогает определить место изменения, выбрать принятый способ решения задачи и найти подробную инструкцию.

Правила skill служат исходным выбором для нового и изменяемого кода. Если проект уже использует другие библиотеки, структуру или соглашения, следуй проекту. Не добавляй параллельное решение и не начинай частичную миграцию без отдельной задачи.

Сохранение существующего стиля не отменяет обязательный способ создания новых TSX-файлов, описанный ниже.

## Как работать с документацией

1. Изучи существующий код, настройки и команды проекта.
2. Определи, какая прикладная область владеет изменяемым поведением, и начни с её главного документа.
3. Открывай документ технологии или библиотеки, только когда прикладная задача и место кода уже понятны.
4. Перед созданием любого нового `.tsx` выполни [инструкцию генерации](reference/application/components/tsx-generation.md).
5. Примени правила кода к изменяемым файлам и выполни проверки проекта.

## Создание TSX

Новые `.tsx` создавай только через `npx @gromlab/create` из локальных шаблонов приложения. Это обязательный шаг для
всех прикладных областей, включая провайдеры, гарды, маршрутные границы и внутренние компоненты без собственного DOM.
Область действия, системные исключения и порядок адаптации определяет
[`инструкция генерации`](reference/application/components/tsx-generation.md). Не заменяй запуск CLI ручным созданием или
копированием файлов. Изменение существующего кода не требует повторной генерации.

## Демонстрационное приложение

[`demo-app/`](demo-app/) представляет запускаемую React SPA, которая подтверждает совместную работу правил skill. Сейчас в ней
находятся общий каркас и законченный сценарий JWT-авторизации с `generated` REST-клиентом, MSW, доменными адаптерами, SWR,
формой входа и защищённым кабинетом пользователя.

Используй `demo-app` как источник проверяемых реализаций правил. Документы должны ссылаться на относящийся к правилу файл
или юнит приложения, а не на отдельный каталог учебных фрагментов. Не копируй всё дерево демо без подтверждённого владельца
и ответственности: эталонным является показанное решение, а не обязательный набор каталогов для любой задачи.
