# Шаблоны React SPA

Этот каталог содержит рабочие шаблоны демо. Перед созданием файла примени
[`обязательную инструкцию генерации TSX`](../../reference/application/components/tsx-generation.md) и прочитай все файлы
выбранного шаблона. Механика CLI описана в [`@gromlab/create`](../../reference/libraries/create/README.md).

| Шаблон | Результат |
| --- | --- |
| `ui-component` | Папка внутреннего компонента с реализацией, типом свойств и CSS Module, без фасета |
| `ui-unit` | Та же форма с публичным фасетом `index.ts` для самостоятельного компонента-юнита |

Названия шаблонов не ограничивают слой или назначение компонента. Провайдер, гард, маршрутная граница и экран используют
тот же каркас. Наличие публичного экспорта у домена само по себе не требует `ui-unit` для внутреннего компонента.

## Команды

Запускай из корня `demo-app`, где лежат `package.json` и `.templates/`:

```bash
npm run create -- ui-component status-label src/compositions/screens/account/ui
npm run create -- ui-unit empty-state src/ui
```

Команда `create` запускает закреплённый `@gromlab/create` через `npx`. Аргумент пути указывает родительский каталог,
а папку `status-label` или `empty-state` создаёт CLI по выбранному шаблону. Примеры применяются только для новой сущности
с подтверждённым владельцем; не запускай их поверх существующих файлов.

## Начальный каркас

Оба шаблона используют только переменную `name` и создают:

```text
component-name/
├── component-name.tsx
├── styles/
│   └── component-name.module.css
└── types/
    └── component-name-props.type.ts
```

`ui-unit` дополнительно создаёт `index.ts`. Зависимости каркаса: React, `clsx` и CSS Modules, уже настроенные в демо.
Назначение компонента, свойства, корневой элемент, стили и экспорты адаптируются в том же изменении по
[`правилам адаптации`](../../reference/application/components/tsx-generation.md#адаптация-каркаса).

Не сохраняй демонстрационную обёртку у компонента без DOM. Неиспользуемые CSS Module и тип свойств удаляются,
но собственная папка компонента остаётся. Проверяемый пример без DOM:
[`AuthenticationProvider`](../src/domains/authentication/providers/authentication-provider/).

Исходники шаблонов редактируются здесь целиком. Не создавай второй набор, генерацию одного шаблона из другого или
символические ссылки. После изменения проверь оба шаблона и соответствие их общих частей.
