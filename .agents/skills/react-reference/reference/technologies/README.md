# Технологии

Этот раздел описывает технологии и технические подходы, принятые в проекте. Для каждой технологии определяется, что она собой представляет, для каких задач используется и какими библиотеками реализуется.

Технология не равна библиотеке. Технология определяет общий способ решения задачи, а библиотека предоставляет конкретные API, конфигурацию и инструменты. Правила размещения и использования решения в приложении относятся к соответствующей области разработки.
