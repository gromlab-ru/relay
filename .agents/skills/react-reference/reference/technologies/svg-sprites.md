# SVG sprites

SVG sprites используются для объединения project-owned SVG-иконок в единый sprite и их типизированного подключения в React.

Для генерации и использования sprite применяется [`@gromlab/svg-sprites`](../libraries/svg-sprites.md). Иконки внешних UI-библиотек используются через API соответствующих библиотек и не копируются в project-owned sprite.

Правила выбора источника иконки и размещения sprite в приложении описаны в разделе [`Иконки`](../application/icons/README.md).
