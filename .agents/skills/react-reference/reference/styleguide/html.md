# HTML

Применяй к `.html` и HTML-частям шаблонов. Для JSX/TSX используй отдельный framework-референс: синтаксис похож, но правила выражений и conditional rendering отличаются.

## Элементы и атрибуты

- Теги и атрибуты пиши в нижнем регистре.
- Строковые значения атрибутов пиши в двойных кавычках.
- Статический boolean-атрибут записывай без значения: `disabled`, а не `disabled="true"`.
- Не добавляй пустые, дублирующиеся и неиспользуемые атрибуты.
- Короткий элемент с небольшим числом атрибутов оставляй в одну строку.
- В многострочном элементе размещай каждый атрибут отдельно.
- Элементы с вложенным содержимым оформляй так, чтобы структура DOM читалась по отступам.

```html
<button
  type="submit"
  name="save"
  disabled
>
  Сохранить
</button>
```

## Семантика

- Используй нативный элемент, соответствующий назначению контента или действия.
- Не добавляй wrapper только ради форматирования.
- Учитывай влияние wrapper на DOM, layout и доступность.
- Не меняй семантику и ARIA в style-only задаче.
- Выбор семантического элемента, ARIA и поведения формы рассматривай как отдельную accessibility-задачу.

## Комментарии

- По умолчанию не комментируй разметку.
- Оставляй комментарий только для внешнего ограничения, workaround или неочевидной причины.
- Используй однострочную форму: `<!-- Причина. -->`.
- Не описывай комментариями очевидные секции, если структуру можно выразить элементом или именем шаблона.

## Проверка

- Теги, атрибуты, кавычки и boolean-атрибуты оформлены единообразно.
- DOM-структура читается по отступам.
- Нет пустых атрибутов и случайных wrappers.
- Семантика не изменена без соответствующей задачи.
- Комментарии объясняют только неочевидные ограничения.
