# PostCSS

PostCSS является принятым обработчиком CSS в React + Vite приложении. Он:

- передаёт общие объявления `@custom-media` каждому CSS-файлу;
- преобразует именованные медиавыражения;
- преобразует вложенность;
- добавляет браузерные префиксы по Browserslist проекта.

CSS Modules предоставляет Vite. PostCSS обрабатывает их содержимое, но не создаёт локальные имена классов.

## Порядок работы

1. Проверь существующую обработку CSS и установи зависимости по [`setup.md`](setup.md).
2. Создай `postcss.config.mjs` и три начальных файла по [`configuration.md`](configuration.md).
3. Подключи `src/ui/themes/styles/index.css` один раз внутри проектного `ThemeProvider`.
4. Пиши CSS по [`styleguide/css.md`](../../styleguide/css.md).
5. Проверь производственную сборку и итоговый CSS.

## Ограничения

- Не заменяй существующую рабочую обработку CSS без отдельной задачи.
- Не добавляй второй плагин или набор настроек для той же возможности.
- Не создавай параллельные хранилища переменных и медиавыражений.
- Не задавай поддерживаемые браузеры в нескольких местах.
- Не считай наличие зависимостей и конфигурации подтверждением работы без производственной сборки.
