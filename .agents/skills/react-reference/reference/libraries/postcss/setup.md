# Установка PostCSS

Перед установкой проверь `package.json`, lock-файл, существующий `postcss.config.*`, общие стили, CSS Modules и
Browserslist. Если проект уже предоставляет такую же обработку CSS, используй её и не устанавливай второй набор
плагинов.

## Зависимости

| Пакет | Ответственность |
| --- | --- |
| `postcss` | Запускает обработку CSS |
| `@csstools/postcss-global-data` | Передаёт общие объявления `@custom-media` каждому CSS-файлу |
| `postcss-custom-media` | Преобразует именованные медиавыражения |
| `postcss-nesting` | Преобразует вложенность |
| `autoprefixer` | Добавляет префиксы по Browserslist проекта |

Установи пакеты как зависимости разработки в пакете приложения:

```bash
npm install --save-dev postcss @csstools/postcss-global-data postcss-custom-media postcss-nesting autoprefixer
```

Используй пакетный менеджер и соответствующую ему команду, уже принятые в проекте.

Vite автоматически применяет найденную конфигурацию PostCSS к импортированным CSS-файлам и CSS Modules. Не добавляй
ручной запуск PostCSS в `vite.config.*` и не устанавливай отдельный плагин CSS Modules.

После установки создай конфигурацию и начальные файлы по [`configuration.md`](configuration.md).

## Проверка установки

- Зависимости добавлены в пакет приложения.
- Lock-файл обновлён пакетным менеджером проекта.
- В проекте нет другого плагина или набора настроек с той же ответственностью.
- Команды разработки и сборки не заменены.
- Сборка приложения выполняется через Vite.
