# Установка Mantine

Перед установкой проверь `package.json`, lock-файл, существующую библиотеку компонентов, импорты `@mantine/*`,
провайдеры приложения и подключённые общие стили.

Если Mantine уже установлен, сохраняй принятую версию и способ настройки. Все пакеты `@mantine/*` должны использовать
одну версию.

## Основные пакеты

Установи Mantine в пакет приложения:

```bash
npm install @mantine/core @mantine/hooks
```

Используй пакетный менеджер проекта. Например, для pnpm:

```bash
pnpm add @mantine/core @mantine/hooks
```

| Пакет | Ответственность |
| --- | --- |
| `@mantine/core` | Компоненты, тема, `MantineProvider` и основные хуки темы |
| `@mantine/hooks` | Общие хуки для поведения интерфейса и браузерных возможностей |

Не устанавливай `@mantine/form`, `@mantine/dates`, `@mantine/notifications` и другие дополнительные пакеты заранее.
Добавляй пакет, когда он требуется конкретной области приложения, и используй ту же версию, что у `@mantine/core`.

Если приложение содержит форму, установи `@mantine/form` пакетным менеджером проекта:

```bash
npm install @mantine/form
```

Для pnpm:

```bash
pnpm add @mantine/form
```

Правила создания формы и применения `useForm` находятся в
[`application/forms`](../../application/forms/README.md).

## После установки

1. Подключи слоистые стили `@mantine/core` в общей точке входа CSS.
2. Создай тему и проектный `ThemeProvider` в `ui/themes`.
3. Подключи `ThemeProvider` один раз в корневой композиции приложения.

Точная конфигурация находится в [`configuration.md`](configuration.md).

## Проверка

- Пакеты добавлены в пакет приложения, а lock-файл обновлён его пакетным менеджером.
- Все пакеты `@mantine/*` используют одну версию.
- `@mantine/form` установлен только в приложении, которому требуется форма.
- В приложении нет второй библиотеки компонентов с той же ответственностью.
- Стили и `MantineProvider` не подключены повторно.
