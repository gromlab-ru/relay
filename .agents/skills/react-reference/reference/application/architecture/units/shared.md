# Фундаментальные юниты shared

Юнит слоя `shared` владеет связным чистым контрактом без предметной, проекционной, технической интеграционной или
визуальной ответственности. Его результат детерминирован входными данными и не зависит от среды выполнения приложения.

## Что принадлежит слою

В `shared` могут находиться:

- чистые преобразования;
- фундаментальные типы;
- детерминированные алгоритмы;
- общие контракты неизвестных сбоев;
- небольшие неизменяемые значения.

Связный набор с самостоятельной ответственностью и публичным контрактом оформляется юнитом `shared`. Одиночный
вспомогательный файл без отдельной границы может находиться непосредственно в `shared`.

## Граница

Юнит `shared` не должен:

- обращаться к сети, браузерному хранилищу или другому вводу-выводу;
- зависеть от React и жизненного цикла фреймворка;
- использовать предметные модели;
- отображать UI;
- настраивать внешнюю библиотеку;
- становиться местом для кода только из-за нескольких потребителей.

Повторное использование не является достаточным критерием. Сначала найди ближайшего смыслового владельца в
`compositions`, `domains`, `infra` или `ui`. Переноси код в `shared` только при отсутствии этих ролей и полностью чистом
контракте.

## Общий контракт сбоя

`ApplicationDefect` является ответственностью `shared`: он одинаково представляет неизвестный сбой для разных слоёв и
не выполняет диагностику самостоятельно.

```text
shared/errors/
├── index.ts
└── application-defect.ts
```

```ts
export { ApplicationDefect, toApplicationDefect } from './application-defect'
```

Отправка диагностического события, очистка чувствительных данных и интеграция с SDK телеметрии принадлежат отдельному
инфраструктурному юниту. Контракт `shared` не импортирует этот юнит и не знает, как будет обработан сбой.

## Публичный API

Фасет публикует только связный фундаментальный контракт. Не создавай общий фасет для несвязанных вспомогательных
функций и типов. Потребители импортируют юнит `shared` через фасет, как и любой другой юнит:

```ts
import { toApplicationDefect } from 'shared/errors'
```

## Проверка

- Контракт не содержит продуктового, проекционного, визуального или интеграционного смысла.
- Результат не зависит от сети, браузера, React или изменяемого глобального состояния.
- Для кода не существует более близкого владельца в другом слое.
- Фасет объединяет одну фундаментальную ответственность, а не случайный набор общего кода.
- Интеграция и побочные эффекты вынесены в инфраструктурные юниты.
