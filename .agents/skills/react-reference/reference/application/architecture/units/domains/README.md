# Домены

Доменный юнит владеет одной предметной возможностью приложения: её языком, контрактом, моделями, операциями,
ожидаемыми исходами, состоянием и доменным UI. Общие критерии юнита и направления зависимостей определяет skill
`unit-architecture`; если он недоступен, используй
[публичный репозиторий](https://github.com/gromlab-ru/unit-architecture). Фасеты и значения сегментов определяет
[`архитектурный профиль React SPA`](../../project-profile.md).

## Граница домена

Любой потребитель за пределами доменного юнита работает с предметными данными только через публичный фасет домена.

Домен публикует необходимые предметные операции. Их адаптеры принимают предметные входные данные, обращаются к
внешнему источнику и возвращают предметный результат либо предусмотренную доменную ошибку. Для GET-данных, участвующих
в отображении React, домен дополнительно публикует хук владельца данных.

За пределами домена не вызывай напрямую API-клиент, REST-операцию, SDK, хранилище или другой источник его предметных
данных. Не выноси наружу исходные DTO, технические ошибки источника и преобразование его ответов.

Технические возможности без предметного владельца, например телеметрия или локализация, используются через
соответствующие инфраструктурные юниты. Визуальная тема и подключение Provider библиотеки компонентов принадлежат
`ui/themes`.

Наличие React-компонентов не превращает домен в композицию. Относи UI к домену, только если он предоставляет
самостоятельный предметный визуальный контракт, не зависит от конкретного маршрута или экрана и может одинаково
применяться в нескольких проекциях. Использование доменной модели, операции или публичного хука само по себе не определяет
владельца UI.

Одноразовые разметка, сообщения и действия законченного экранного сценария принадлежат композиции. Доменный компонент
может получать конкретные варианты отображения через свойства. Например,
[`AuthGuard`](../../../../../demo-app/src/domains/authentication/ui/auth-guard/auth-guard.tsx) выбирает состояние
авторизации для маршрута и произвольного защищённого фрагмента, а внешний владелец передаёт отображение состояний.

## Поток данных

```text
потребитель
→ публичный доменный хук или операция
→ доменный адаптер
→ API-клиент / SDK / хранилище
→ исходный DTO
→ внутренний mapper
→ доменная модель
→ кеш / состояние / UI
```

Публичная функция адаптера сама является доменной операцией: не добавляй поверх неё обёртку, которая только повторяет
вызов. Хук может использовать адаптер внутри домена и добавлять жизненный цикл или кеш, но не заменяет контракт
операции.

Известная ошибка источника преобразуется в ожидаемую доменную ошибку. Для изменяющей или императивной операции неизвестный
сбой преобразуется в `ApplicationDefect` и передаётся границе приложения. GET-адаптер для типизированного SWR-хука
преобразует каждый неуспешный исход в ошибку своего публичного контракта по правилам
[`errors.md`](errors.md#граница-get-адаптера-для-swr).
