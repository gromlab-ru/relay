# Платформа React SPA

Этот раздел описывает окружение браузера и сборки React SPA. Конфигурация платформы не является выполняемым юнитом,
но доступ к возможностям окружения из кода приложения должен иметь явного технического владельца.

## Vite

Используй Vite с официальным плагином React как сервер разработки и средство производственной сборки. Сохраняй
существующую конфигурацию проекта и не добавляй другое средство сборки без отдельной задачи на миграцию.

Конфигурация сборки отвечает за преобразование React, статические файлы, алиасы, переменные окружения и необходимые
плагины. Она не получает искусственный выполняемый фасет только ради соответствия архитектурному дереву.

Алиасы `app/*`, `compositions/*`, `domains/*`, `infra/*`, `ui/*` и `shared/*` настрой одновременно для TypeScript и
Vite по [`module-aliases.md`](module-aliases.md). Не добавляй префикс `@/` и не создавай отдельные алиасы для юнитов или
сегментов.

## Переменные окружения

Значения времени сборки поступают через переменные окружения Vite. Доступ к `import.meta.env` централизуется в
техническом владельце, который:

- читает только ожидаемые ключи;
- проверяет обязательные значения;
- преобразует строки в типизированный контракт приложения;
- сообщает об ошибочной конфигурации до выполнения зависимого сценария.

Код приложения не читает `import.meta.env` напрямую. Любое значение клиентской сборки доступно пользователю, поэтому
секреты не помещаются в конфигурацию браузера.

## Даты и локализация

Day.js является основной библиотекой разбора, форматирования и преобразования дат. Формат транспортного контракта,
локаль и часовой пояс задаются явно и не зависят от неявных настроек браузера.

Добавляй локализацию только при наличии продуктового требования. Если проект уже использует i18n, следуй принятой
библиотеке, владельцу переводов и правилам форматирования.

## Проверка

- Производственная сборка использует те же обязательные переменные окружения, что и развёртывание.
- TypeScript, Vite и тесты одинаково разрешают алиасы слоёв.
- Код браузера не содержит секреты и серверные зависимости.
- Статические файлы и динамические чанки разрешаются с производственного базового URL.
- Даты не меняют смысл из-за неявной локали или часового пояса.
