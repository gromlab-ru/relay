Раздел предназначен для разработчиков и сопровождающих самого пакета. Пользователям generated SDK и runtime primitives эти материалы для обычной интеграции не требуются.

- [Архитектура проекта](./architecture.md) - компоненты пакета, pipeline генерации и embedded runtime.
- [Тестирование проекта](./testing.md) - команды, contract suites, fixtures и coverage requirements.

Пользовательская документация включает [CLI](../cli.md), [`HttpClient`](../http-client.md) и [рецепты интеграции](../recipes/index.md).
