# Пакет

В монорепозитории REST-клиент хранится в отдельном workspace-пакете. Для consumers из разных репозиториев тот же пакет можно публиковать в npm-реестр.

## Выберите вариант

| Вариант | Когда подходит |
| --- | --- |
| [Пакет в монорепозитории](./monorepo-package.md) | Все приложения находятся в одном репозитории |
| [Отдельный npm-пакет](./npm-package.md) | Клиент нужен приложениям из разных репозиториев |

Если клиент нужен только одному приложению, проще разместить его внутри существующей инфраструктурной структуры проекта. Базовый пример показан в разделе [React](../react/full-client.md).

## Дополнительные возможности

- [Исправление операции внутри SDK-пакета](./generated-with-corrections.md).

## Основные правила

- Сгенерированные файлы не редактируются вручную.
- Перед сборкой каталог `dist` очищается.
- Поле `exports` задаёт поддерживаемые пути импорта.
- `sideEffects: false` используется только в пакете без побочных эффектов при импорте.
- Временные исправления удаляются после обновления OpenAPI и выпуска новой версии.

Примеры подключения клиента находятся в разделах [React](../react/index.md) и [Next.js](../nextjs/index.md).
