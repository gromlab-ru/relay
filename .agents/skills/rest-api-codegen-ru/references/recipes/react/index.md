# React + Vite

В этом разделе API-клиент работает в браузере. Адрес сервера, авторизация и обработка ошибок настраиваются один раз в `HttpClient`.

## Подключить API

- [Полный клиент](./full-client.md) - регенерация и сборка API-клиента из полного дерева операций.
- [Ручной клиент без OpenAPI](./manual-client.md) - типы и запросы описываются в приложении.
- [Исправление неверно описанного метода](./broken-endpoints.md) - временная замена одного сгенерированного запроса.

## Работать с серверными данными

## Что выбрать

| Потребность | Решение |
| --- | --- |
| Нужна большая часть API | [Полный клиент](./full-client.md) |
| Хук вызывает один метод | [SWR](./swr.md) |
