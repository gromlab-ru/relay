# Модель данных

[Главная инструкция](../skill.md). Все сущности принадлежат одному проекту;
workspace регистрирует проекты, не объединяя их данные.

Продукт описывается паспортом, фичами и сценариями. Приложение объявляет реализации
общих требований. Документы сохраняют Markdown и типизированные области.
Доски объединяют задачи; продуктовая и инфраструктурная создаются при init,
прикладная — при создании приложения. Ключи задач используют префиксы досок.

План работ (`work-plan`, PLN-N) организует этапы (`plan-stage`, STG-N) со ссылками на
существующие задачи. У задачи одно текущее участие, закрытые включения сохраняются.
Релиз (`release`, REL-N) выбирает планы целиком и при явном выпуске сохраняет
самодостаточный снимок. Состояния задачи, плана и релиза независимы. Текущий прогресс
не переписывает исторический выпуск. [Планы](PLANNING.md), [релизы](RELEASES.md).

Сущности адресуются ключом или ID, хранят связи по ID. Смена ключа сохраняет алиасы.
Родительство и зависимости задач различаются. Произвольное отношение графа не меняет
предметную готовность автоматически. История и квитанции принадлежат владельцам записей.
