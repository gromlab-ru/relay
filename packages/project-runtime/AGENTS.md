# Общие подключения CLI и MCP

Прочитай `../../docs/development/INTERFACE-STANDARD.md`.
Backend сохраняет единый предметный контракт для local и HTTP. Форматирование остаётся
в CLI/MCP, дисковая сериализация — в Core. Полные описания передаются как Markdown,
а не как потерявший разметку краткий текст.
Явно проверяй выбор проекта, перепривязку реестра, ошибки соединения и повтор записи.
Описания конфигурации и диагностика пишутся по-русски.
