# Server runtime: обязательные правила

Прочитай `../../docs/development/INTERFACE-STANDARD.md`.
HTTP использует общие сервисы Core; не дублируй правила записи в контроллерах.
Для каждой операции опиши по-русски назначение, аргументы, ошибки и ограничения.
Текстовые поля сохраняют семантику Markdown или многострочного обычного текста.
При изменении схем проверь OpenAPI, сгенерированный SDK, CLI, MCP и границы проекта.
При изменении хранения проверь SSE после прямой CLI-записи, включая новые подкаталоги.
Проверки должны покрывать конфликт ревизий, повтор и изоляцию проектов.
