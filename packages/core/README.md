# Ядро задач

Общие domain/application/storage-модули для CLI и NestJS. Импорт: `#core/*`.
Ядро выполняет проверки схем, графа, назначения, ревизии, порядка и атомарную запись.
JSON-задачи находятся непосредственно в `storageDir`; служебные данные — в соседнем
игнорируемом runtime-каталоге на той же файловой системе.

Ядро возвращает данные. HTTP-ответы, терминальное оформление и React-компоненты
находятся в соответствующих приложениях.

Тесты ядра — `packages/core/test`, CLI-интеграция — `apps/cli/test`. При изменении бизнес-правил дополнить
проверки CLI и согласовать REST DTO с `packages/contracts`.
