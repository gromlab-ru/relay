# Ядро сущностей и предметных операций

Обязательные правила — [AGENTS.md](AGENTS.md) и
[стандарт интерфейсов](../../docs/development/INTERFACE-STANDARD.md).
Продуктовый репозиторий разделяет публичный DTO и дисковую схему v2: Markdown хранится
массивами строк, записи разложены по типам. Старый формат читается совместимо;
перенос выполняет `product migrate`. Подробности — [продукт](../../docs/reference/PRODUCT.md).

Общие domain/application/storage-модули для CLI и NestJS. Импорт: `@relay/core/*`.
Ядро выполняет проверки схем, графа, назначения, ревизии, порядка и атомарную запись.
JSON-задачи находятся непосредственно в `storageDir`; служебные данные — в соседнем
игнорируемом runtime-каталоге на той же файловой системе.

Ядро возвращает данные. HTTP-ответы принадлежат `packages/server-runtime`,
терминальное оформление — `apps/cli`, React-компоненты — `apps/web`.

`application/entities` — общий движок девяти видов: каталог определений и записей,
резолвер ключей/ID, фильтры, история адресов и зарегистрированные обработчики изменений.
Резолвинг и запись выполняются под одной блокировкой; внутренние ссылки используют ID.
Переносимые схемы принадлежат `@relay/contracts`, прежние domain-импорты остаются фасадами.
[Контракт](../../docs/reference/ENTITIES.md), [архитектурное решение](../../docs/engineering/decisions/entity-engine.md).

`src/application/queries/tasks.ts` предоставляет согласованный снимок и его версию,
полную доску с фильтрами и курсорами, компактные карточки и детальные связи задачи.
`src/application/queries/records.ts` — общая пагинация комментариев и отчётов с байтовым бюджетом.
Эти операции не зависят от Nest, HTTP DTO или терминального представления.

Тесты ядра — `packages/core/test`, CLI-интеграция — `apps/cli/test`. При изменении бизнес-правил дополнить
проверки CLI и согласовать REST DTO с `packages/contracts`.
