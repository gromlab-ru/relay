# История изменений

## Не выпущено

- Единственный числовой `id` задачи: от 1, следующий равен максимальному существующему плюс один. Файлы и все ссылки используют тот же ID; поле `number` удалено.
- Формат задач v2 и команда `migrate`: перенос UUID-документов со всеми связями и контекстом, сохранение исходников и возобновление после прерывания.
- Рабочий `list`: все незавершённые задачи по группам, включая заблокированные; `--all` включает конечные статусы, явный `--status` выбирает заданный статус.
- Количество задач в `list` ограничено только байтовым бюджетом или явным `--limit`; большие списки имеют продолжение и счётчик «показано N из M». `--all` совместим с `--limit` / `--cursor`.
- ID блокеров рядом со статусом; подсказка истории для пустого рабочего списка.
- Цвет каждого статуса в конфиге через `statuses.<имя>.color`.
- Справка всех команд с объяснениями, аргументами, общими параметрами и примерами; подсказки при ошибках.
- `create "Название"` в дополнение к `--title`; `claim --status` для атомарного назначения и перехода.
- Единый формат регистрации команд, общие источники текстового ввода и руководство расширения CLI.
- Прямое чтение карточки и её связей; один снимок графа на изменение вместо повторного чтения всей базы.
- Краткий README с таблицей возможностей и примерами через `npx`; playground в новом формате.

## 0.2.0

- Постоянные номера задач от 1; команды принимают номера в аргументах, родителях и зависимостях.
- Команда `number` для старых документов и устранения совпадений номеров после Git-слияния.
- Цветные статусы, таблицы, карточки, дерево связей и оформление комментариев и отчётов.
- Подсветка Markdown и распространённых блоков кода; перенос по ширине терминала.
- Управление цветом через `--color auto|always|never`, `NO_COLOR` и `FORCE_COLOR`.
- Текстовые ответы для всех команд и ошибок; JSON-режим без ANSI-последовательностей.
- Байтовая пагинация учитывает полное оформление, включая цветовые коды.

## 0.1.0
