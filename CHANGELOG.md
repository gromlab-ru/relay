# История изменений

## 0.2.0

- Постоянные номера задач от 1; команды принимают номера в аргументах, родителях и зависимостях.
- Команда `number` для старых документов и устранения совпадений номеров после Git-слияния.
- Цветные статусы, таблицы, карточки, дерево связей и оформление комментариев и отчётов.
- Подсветка Markdown и распространённых блоков кода; перенос по ширине терминала.
- Управление цветом через `--color auto|always|never`, `NO_COLOR` и `FORCE_COLOR`.
- Текстовые ответы для всех команд и ошибок; JSON-режим без ANSI-последовательностей.
- Байтовая пагинация учитывает полное оформление, включая цветовые коды.

## 0.1.1

Первый выпуск через GitHub Actions с npm Trusted Publishing (OIDC) и provenance.

## 0.1.0

Первый публичный выпуск.

- Node.js CLI для AI-оркестратора, субагентов и человека.
- Одна задача — один JSON с описанием, комментариями и отчётами.
- Многострочный Markdown в хранилище и читаемом выводе CLI.
- Группы, теги, подзадачи, зависимости и настраиваемые статусы.
- Атомарное назначение, защита revision и проверка графа.
- Пагинация, ограничение выдачи, выборочное чтение и поиск отчётов.
- GitHub Actions для Node.js 22/24, проверки npm-архива и релиза по тегу.
